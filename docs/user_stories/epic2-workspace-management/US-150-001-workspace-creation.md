# US-150-001: 워크스페이스 생성

**As a** 사용자  
**I want to** 개인 프로젝트와 팀 프로젝트를 분리하여 관리하기 위해 별도의 워크스페이스를 만들고  
**So that** 프로젝트를 체계적으로 구분할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - Personal 워크스페이스 생성**
```gherkin
Given 사용자가 대시보드에 있고
And 사용자당 워크스페이스 수가 10개 미만일 때
When 워크스페이스 생성 버튼을 클릭하고
And 워크스페이스 이름을 입력하고
And Personal 타입을 선택하고
And 생성 버튼을 클릭하면
Then 새로운 Personal 워크스페이스가 생성되고
And 워크스페이스 목록에 표시되고
And "워크스페이스가 성공적으로 생성되었습니다" 메시지가 표시된다
```

**✅ 성공 케이스 - Team 워크스페이스 생성**
```gherkin
Given 사용자가 대시보드에 있고
And 사용자당 워크스페이스 수가 10개 미만일 때
When 워크스페이스 생성 버튼을 클릭하고
And 워크스페이스 이름을 입력하고
And Team 타입을 선택하고
And 생성 버튼을 클릭하면
Then 새로운 Team 워크스페이스가 생성되고
And 워크스페이스 목록에 표시되고
And 멤버 초대 기능이 활성화된다
```

**❌ 실패 케이스 - 워크스페이스 수 제한 초과**
```gherkin
Given 사용자가 이미 10개의 워크스페이스를 가지고 있고
When 새로운 워크스페이스를 생성하려고 시도하면
Then "워크스페이스는 최대 10개까지 생성할 수 있습니다" 오류 메시지가 표시되고
And 워크스페이스 생성이 진행되지 않는다
```

**❌ 실패 케이스 - 빈 워크스페이스 이름**
```gherkin
Given 사용자가 워크스페이스 생성 모달에 있고
And 워크스페이스 이름을 입력하지 않았을 때
When 생성 버튼을 클릭하면
Then "워크스페이스 이름을 입력해주세요" 오류 메시지가 표시되고
And 워크스페이스 생성이 진행되지 않는다
```

**Priority:** High | **Story Points:** 5
