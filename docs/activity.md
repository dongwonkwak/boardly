# 활동 내역의 범위와 종류

* 활동 내역은 크게 3가지 수준을 가진다.

## 1. 보드(Board) 수준의 활동 내역

이것이 가장 기본적이고 필수적인 활동 내역입니다.

    위치: 보통 특정 보드 내의 사이드바나 메뉴에 위치합니다.

    내용: 해당 보드 안에서 일어난 모든 활동을 시간순으로 보여줍니다.

        카드 생성, 이동(리스트 변경), 보관(Archive)

        카드 제목, 설명, 마감일 등 내용 변경

        카드에 멤버 할당 또는 제외

        댓글 추가

        체크리스트 항목 추가 및 완료

        첨부파일 추가 등

    대상: 해당 보드의 모든 멤버가 동일한 내용을 봅니다.

## 2. 워크스페이스/팀(Workspace/Team) 수준의 활동 내역

사용자가 여러 보드가 속한 팀이나 워크스페이스의 멤버일 경우, 더 넓은 범위의 활동을 모아 볼 수 있습니다.

    위치: 워크스페이스 대시보드나 별도의 '활동' 페이지에 위치할 수 있습니다.

    내용: 사용자가 멤버로 있는 모든 보드의 활동 내역을 한 곳에 모아서 보여줍니다.

    대상: 주로 팀의 리더나 관리자가 팀 전체의 진행 상황을 조망할 때 유용합니다.

## 3. 사용자 중심(User-centric) 활동 내역 (알림, Notifications)

이는 단순히 모든 활동을 나열하는 것을 넘어, '나'와 직접적으로 관련된 중요한 활동만 필터링해서 보여주는 기능입니다.

    위치: 보통 화면 상단의 '종' 모양 아이콘이나 개인 프로필 페이지에 위치합니다.

    내용:

        누군가 나를 카드에 할당했을 때

        누군가 나를 댓글에서 '@'로 맨션했을 때

        내가 참여하고 있는 카드의 마감일이 임박했을 때

        내가 참여하고 있는 카드에 새로운 댓글이나 첨부파일이 달렸을 때

    대상: 정보의 홍수 속에서 사용자가 놓치지 말아야 할 핵심적인 내용을 전달하는 데 목적이 있습니다.
