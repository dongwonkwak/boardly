# US-603-001: 개인 알림 센터

**As a** 사용자  
**I want to** 정보의 홍수 속에서 놓치지 말아야 할 핵심적인 내용만 선별적으로 확인하고  
**So that** 효율적으로 작업을 관리할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 개인 알림 센터 조회**
```gherkin
Given 사용자가 헤더의 알림 아이콘을 클릭했을 때
When 알림 센터가 열리면
Then 나와 직접 관련된 알림만 시간순으로 표시되고
And 읽지 않은 알림이 강조 표시되고
And 각 알림의 타입(담당자 할당, 댓글, 마감일 등)이 아이콘으로 구분된다
```

**✅ 성공 케이스 - 알림 필터링**
```gherkin
Given 사용자가 알림 센터에 있을 때
When 특정 알림 타입으로 필터링하면
Then 선택한 타입의 알림만 표시되고
And 필터 상태가 UI에 명확히 표시된다
```

**✅ 성공 케이스 - 모든 알림 읽음 처리**
```gherkin
Given 사용자가 여러 개의 읽지 않은 알림을 가지고 있을 때
When "모두 읽음 처리" 버튼을 클릭하면
Then 모든 알림이 읽음 상태로 변경되고
And 알림 배지가 사라지고
And "모든 알림이 읽음 처리되었습니다" 메시지가 표시된다
```

**Priority:** Medium | **Story Points:** 4
