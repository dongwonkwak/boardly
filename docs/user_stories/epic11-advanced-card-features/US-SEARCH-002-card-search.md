# US-SEARCH-002: 카드 검색 `[P1]`

**As a** 사용자  
**I want to** 보드 내의 많은 카드 중에서 특정 카드를 빠르게 찾고  
**So that** 효율적으로 작업을 관리할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 카드 제목 검색
```gherkin
Given 사용자가 보드에 있고
And 보드에 많은 카드가 있을 때
When 검색창에 카드 제목의 키워드를 입력하면
Then 해당 키워드가 포함된 카드들만 표시되고
And 매칭되지 않는 카드들은 숨겨지고
And 검색 키워드가 하이라이트되어 표시된다
```

### ✅ 성공 케이스 - 카드 설명 검색
```gherkin
Given 사용자가 보드에서 카드 검색을 수행할 때
When 카드 설명에 포함된 키워드를 입력하면
Then 해당 키워드가 설명에 포함된 카드들이 표시되고
And 마크다운 형식의 설명도 검색 대상에 포함된다
```

### ✅ 성공 케이스 - 검색 중 실시간 필터링
```gherkin
Given 사용자가 카드 검색창에 키워드를 입력하고 있을 때
When 타이핑하는 동안
Then 실시간으로 매칭되는 카드들이 필터링되고
And 검색 결과가 즉시 업데이트된다
```

**Priority:** Medium | **Story Points:** 5
