# Notion 동기화 가이드

## 개요

Boardly 프로젝트의 docs 폴더 내 문서들은 자동으로 Notion의 "공유된 문서" 페이지와 동기화됩니다.

## 동기화 대상

### 문서 구조 매핑
```
docs/
├── architecture/          → ## Architecture (h2 제목)
├── design/                → ## Design (h2 제목)  
├── management/            → ## Management (h2 제목)
├── planning/              → ## Planning (h2 제목)
├── principles/            → ## Principles (h2 제목)
└── README.md              → 공유된 문서 페이지의 상단 소개
```

## 동기화 트리거

### 자동 동기화 상황
- `.md` 파일 생성, 수정, 삭제
- 폴더 구조 변경
- 사용자 명시적 요청

### Cursor AI 지원
프로젝트는 Cursor AI가 문서 변경사항을 감지하고 자동으로 Notion 동기화를 제안하도록 설정되어 있습니다.

## 문서 작성 가이드

### 제목 규칙
- 첫 번째 `# 제목`이 Notion 페이지 제목이 됩니다
- `## 제목`은 heading_2 블록으로 변환됩니다
- `### 제목`은 heading_3 블록으로 변환됩니다

### 마크다운 지원
- **굵은글씨**, *기울임체*, `인라인 코드` 지원
- 불릿 목록, 숫자 목록 지원
- 코드 블록, 인용문 지원
- 테이블은 제한적 지원

## 주의사항

1. **파일 크기**: 10MB 이하 권장
2. **이미지**: 로컬 이미지는 업로드 후 URL 변경됨
3. **특수 문자**: Notion 미지원 마크다운 구문 주의
4. **동시 편집**: Notion과 로컬 파일 동시 편집 시 충돌 가능

## Notion 워크스페이스 정보

- **워크스페이스**: 포트폴리오
- **루트 페이지**: 공유된 문서
- **페이지 ID**: `260c6221-cd14-80a9-bb57-cf1a235c5834`

## 수동 동기화

필요시 Cursor AI에게 다음과 같이 요청하세요:
```
"docs/[파일명].md를 Notion과 동기화해주세요"
```

## 문제 해결

### 동기화 실패 시
1. 인터넷 연결 확인
2. Notion 권한 확인  
3. 마크다운 문법 검증
4. Cursor AI에게 재시도 요청

### 문의사항
동기화 관련 문제나 개선사항은 프로젝트 관리자에게 문의하세요.
