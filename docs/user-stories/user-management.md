# 사용자 관리 유저스토리

## Epic: 사용자 관리
**목표**: 사용자가 Boardly 서비스에 가입하고, 로그인하며, 프로필을 관리할 수 있다.

---

## User Story 1: 회원가입하기

**As a** 새로운 사용자  
**I want to** Boardly 서비스에 회원가입할 수 있다  
**So that** 칸반 보드를 사용하여 프로젝트를 관리할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 회원가입 페이지에 있다  
**When** 이메일 주소를 입력한다  
**And** username을 입력한다  
**And** displayName을 입력한다  
**And** 비밀번호를 입력한다  
**And** 비밀번호 확인을 입력한다  
**And** "회원가입" 버튼을 클릭한다  
**Then** 회원가입이 완료된다  
**And** 개인 워크스페이스가 자동으로 생성된다 (한국어: "개인 워크스페이스", 영어: "My Workspace")  
**And** 사용자가 개인 워크스페이스의 소유자이자 ADMIN이 된다  
**And** 워크스페이스 멤버십 테이블에 ADMIN 역할로 자동 등록된다  
**And** 이메일 인증 페이지로 이동한다  
**And** 성공 메시지가 표시된다

#### 비즈니스 규칙
- 이메일은 고유해야 하며, 유효한 이메일 형식이어야 한다
- username은 고유해야 하며, 대소문자를 구분하지 않는다
- displayName은 필수 입력 항목이다
- 비밀번호는 8자 이상이어야 하며, 영문자, 숫자, 특수문자를 포함해야 한다
- 비밀번호와 비밀번호 확인이 일치해야 한다
- 회원가입 완료 후 이메일 인증이 필요하다
- 회원가입 성공 시 개인 워크스페이스가 자동으로 생성된다
- 개인 워크스페이스 이름은 언어 설정에 따라 다르다 (한국어: "개인 워크스페이스", 영어: "My Workspace")
- 개인 워크스페이스는 PERSONAL 타입, 비공개 설정으로 생성된다
- 사용자는 개인 워크스페이스의 생성자이자 ADMIN 역할을 가진다
- 워크스페이스 멤버십 테이블에 사용자가 ADMIN 역할로 자동 등록된다
- 개인 워크스페이스는 사용자당 1개씩만 생성되며, 나중에 이름 변경이 가능하다
- 워크스페이스 생성에 실패해도 회원가입은 성공으로 처리된다

#### 예외 상황
**Given** 회원가입 폼이 열려있다  
**When** 이미 등록된 이메일로 회원가입을 시도한다  
**Then** "이미 등록된 이메일입니다" 오류 메시지가 표시된다

**Given** 회원가입 폼이 열려있다  
**When** 이미 사용 중인 username으로 회원가입을 시도한다  
**Then** "이미 사용 중인 사용자명입니다" 오류 메시지가 표시된다

**Given** 회원가입 폼이 열려있다  
**When** 비밀번호와 비밀번호 확인이 일치하지 않는다  
**Then** "비밀번호가 일치하지 않습니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 회원가입**: 모든 필수 정보를 올바르게 입력하여 회원가입
2. **개인 워크스페이스 자동 생성**: 회원가입 후 개인 워크스페이스 생성 확인
3. **워크스페이스 생성자 및 권한 확인**: 생성된 워크스페이스의 생성자이자 ADMIN이 사용자인지 확인
4. **멤버십 테이블 등록 확인**: 워크스페이스 멤버십 테이블에 ADMIN 역할로 등록되었는지 확인
5. **언어별 워크스페이스 이름**: 한국어/영어 설정에 따른 워크스페이스 이름 확인
6. **워크스페이스 생성 실패**: 워크스페이스 생성 실패 시에도 회원가입 성공 처리 확인
7. **중복 이메일**: 이미 등록된 이메일로 회원가입 시도
8. **중복 username**: 이미 사용 중인 username으로 회원가입 시도
9. **비밀번호 불일치**: 비밀번호와 비밀번호 확인이 다른 경우
10. **유효하지 않은 이메일**: 잘못된 이메일 형식 입력

## User Story 2: 로그인하기

**As a** 등록된 사용자  
**I want to** username과 비밀번호로 로그인할 수 있다  
**So that** Boardly 서비스를 이용할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 로그인 페이지에 있다  
**When** username을 입력한다  
**And** 비밀번호를 입력한다  
**And** "로그인" 버튼을 클릭한다  
**Then** 로그인이 성공한다  
**And** 메인 페이지로 이동한다  
**And** 환영 메시지가 표시된다

#### 비즈니스 규칙
- username은 대소문자를 구분하지 않는다
- 로그인 실패 시 5회까지 시도 가능하며, 5회 실패 시 계정이 잠긴다
- 계정 잠금 후 30분 후에 자동으로 해제된다
- 이메일 인증이 완료되지 않은 계정은 로그인할 수 없다

#### 예외 상황
**Given** 로그인 폼이 열려있다  
**When** 존재하지 않는 username으로 로그인을 시도한다  
**Then** "사용자명 또는 비밀번호가 올바르지 않습니다" 오류 메시지가 표시된다

**Given** 로그인 폼이 열려있다  
**When** 잘못된 비밀번호로 로그인을 시도한다  
**Then** "사용자명 또는 비밀번호가 올바르지 않습니다" 오류 메시지가 표시된다

**Given** 사용자가 5회 연속 로그인에 실패했다  
**When** 다시 로그인을 시도한다  
**Then** "계정이 잠겼습니다. 30분 후에 다시 시도해주세요" 메시지가 표시된다

#### 테스트 시나리오
1. **정상 로그인**: 올바른 username과 비밀번호로 로그인
2. **잘못된 username**: 존재하지 않는 username으로 로그인 시도
3. **잘못된 비밀번호**: 올바른 username에 잘못된 비밀번호 입력
4. **대소문자 구분**: username의 대소문자를 다르게 입력해도 로그인 성공
5. **계정 잠금**: 5회 연속 실패 후 계정 잠금 확인
6. **미인증 계정**: 이메일 인증이 완료되지 않은 계정으로 로그인 시도

## User Story 3: 프로필 수정하기

**As a** 로그인된 사용자  
**I want to** 내 프로필 정보를 수정할 수 있다  
**So that** 최신 정보를 유지할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 프로필 설정 페이지에 있다  
**When** displayName을 수정한다  
**And** 프로필 이미지를 업로드한다 (선택사항)  
**And** "저장" 버튼을 클릭한다  
**Then** 프로필 정보가 업데이트된다  
**And** 성공 메시지가 표시된다

#### 비즈니스 규칙
- displayName은 1-50자 사이여야 한다
- displayName은 중복을 허용한다
- 프로필 이미지는 JPG, PNG, GIF 형식만 허용한다
- 프로필 이미지 크기는 5MB 이하여야 한다
- username은 보안상의 이유로 변경할 수 없다
- 이메일 변경 시 재인증이 필요하다

#### 예외 상황
**Given** 프로필 수정 폼이 열려있다  
**When** displayName을 50자를 초과하여 입력한다  
**Then** "표시명은 50자 이하여야 합니다" 오류 메시지가 표시된다

**Given** 프로필 수정 폼이 열려있다  
**When** 지원하지 않는 형식의 이미지를 업로드한다  
**Then** "지원하지 않는 이미지 형식입니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 수정**: displayName과 프로필 이미지 정상 수정
2. **displayName 길이 초과**: 50자 초과 displayName 입력
3. **이미지 형식 오류**: 지원하지 않는 형식의 이미지 업로드
4. **이미지 크기 초과**: 5MB 초과 이미지 업로드
5. **username 변경 시도**: username 변경 필드 비활성화 확인

## User Story 4: 비밀번호 찾기

**As a** 사용자  
**I want to** 비밀번호를 잊어버렸을 때 재설정할 수 있다  
**So that** 계정에 다시 접근할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 비밀번호 찾기 페이지에 있다  
**When** 등록된 이메일 주소를 입력한다  
**And** "비밀번호 재설정" 버튼을 클릭한다  
**Then** 비밀번호 재설정 이메일이 발송된다  
**And** "이메일을 확인해주세요" 메시지가 표시된다

**Given** 사용자가 비밀번호 재설정 이메일을 받았다  
**When** 이메일의 재설정 링크를 클릭한다  
**Then** 비밀번호 재설정 페이지로 이동한다

**Given** 사용자가 비밀번호 재설정 페이지에 있다  
**When** 새로운 비밀번호를 입력한다  
**And** 새로운 비밀번호 확인을 입력한다  
**And** "비밀번호 변경" 버튼을 클릭한다  
**Then** 비밀번호가 성공적으로 변경된다  
**And** 로그인 페이지로 이동한다  
**And** "비밀번호가 변경되었습니다" 메시지가 표시된다

#### 비즈니스 규칙
- 비밀번호 재설정 링크는 24시간 후 만료된다
- 비밀번호 재설정 링크는 한 번만 사용 가능하다
- 새로운 비밀번호는 기존 비밀번호와 달라야 한다
- 비밀번호는 8자 이상이어야 하며, 영문자, 숫자, 특수문자를 포함해야 한다

#### 예외 상황
**Given** 사용자가 비밀번호 찾기 페이지에 있다  
**When** 등록되지 않은 이메일을 입력한다  
**Then** "등록되지 않은 이메일입니다" 오류 메시지가 표시된다

**Given** 사용자가 만료된 재설정 링크를 클릭한다  
**When** 비밀번호 재설정 페이지에 접근한다  
**Then** "만료된 링크입니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 비밀번호 찾기**: 등록된 이메일로 비밀번호 재설정 요청
2. **미등록 이메일**: 등록되지 않은 이메일로 재설정 요청
3. **링크 만료**: 24시간 후 만료된 링크 접근
4. **중복 사용**: 이미 사용된 재설정 링크 접근
5. **동일한 비밀번호**: 기존과 동일한 비밀번호로 변경 시도

## User Story 5: 로그아웃하기

**As a** 로그인된 사용자  
**I want to** 로그아웃할 수 있다  
**So that** 계정 보안을 유지할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 로그인되어 있다  
**When** 사용자 메뉴에서 "로그아웃"을 클릭한다  
**Then** 로그아웃이 완료된다  
**And** 로그인 페이지로 이동한다  
**And** "로그아웃되었습니다" 메시지가 표시된다

#### 비즈니스 규칙
- 로그아웃 시 모든 세션이 종료된다
- 로그아웃 후에는 인증이 필요한 페이지에 접근할 수 없다
- 로그아웃은 즉시 처리된다

#### 테스트 시나리오
1. **정상 로그아웃**: 사용자 메뉴에서 로그아웃 실행
2. **세션 종료 확인**: 로그아웃 후 인증 필요 페이지 접근 시도
3. **브라우저 뒤로가기**: 로그아웃 후 브라우저 뒤로가기 시도

---

## User Story 6: 계정 삭제하기

**As a** 사용자  
**I want to** 내 계정을 삭제할 수 있다  
**So that** 서비스 이용을 중단할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 계정 설정 페이지에 있다  
**When** "계정 삭제" 버튼을 클릭한다  
**Then** 계정 삭제 확인 모달이 표시된다

**Given** 계정 삭제 확인 모달이 열려있다  
**When** "계정 삭제"를 입력한다  
**And** "확인" 버튼을 클릭한다  
**Then** 계정이 삭제된다  
**And** 메인 페이지로 이동한다  
**And** "계정이 삭제되었습니다" 메시지가 표시된다

#### 비즈니스 규칙
- 계정 삭제 시 모든 개인 데이터가 영구적으로 삭제된다
- 생성한 워크스페이스가 있는 경우 삭제할 수 없다
- 다른 사용자와 공유된 보드의 데이터는 유지된다
- 계정 삭제는 되돌릴 수 없다

#### 예외 상황
**Given** 사용자가 워크스페이스 생성자이다  
**When** 계정 삭제를 시도한다  
**Then** "생성한 워크스페이스가 있어 삭제할 수 없습니다" 메시지가 표시된다

**Given** 계정 삭제 확인 모달이 열려있다  
**When** 잘못된 텍스트를 입력한다  
**Then** "정확한 텍스트를 입력해주세요" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 계정 삭제**: 모든 조건을 만족하여 계정 삭제
2. **워크스페이스 생성자**: 생성한 워크스페이스가 있는 경우 삭제 시도
3. **잘못된 확인 텍스트**: 정확하지 않은 텍스트 입력
4. **삭제 취소**: 확인 모달에서 취소 버튼 클릭

## User Story 7: 이메일 인증하기

**As a** 회원가입한 사용자  
**I want to** 이메일 인증을 완료할 수 있다  
**So that** 모든 서비스 기능을 이용할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 회원가입을 완료했다  
**When** 이메일 인증 링크를 클릭한다  
**Then** 이메일 인증이 완료된다  
**And** 메인 페이지로 이동한다  
**And** "이메일 인증이 완료되었습니다" 메시지가 표시된다

#### 비즈니스 규칙
- 이메일 인증 링크는 7일 후 만료된다
- 인증 완료 전에는 로그인할 수 없다
- 인증 완료 후에는 모든 서비스 기능을 이용할 수 있다

#### 예외 상황
**Given** 사용자가 만료된 인증 링크를 클릭한다  
**When** 이메일 인증 페이지에 접근한다  
**Then** "만료된 인증 링크입니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 이메일 인증**: 유효한 인증 링크로 인증 완료
2. **만료된 링크**: 7일 후 만료된 인증 링크 접근
3. **미인증 로그인**: 인증 완료 전 로그인 시도

## User Story 8: 사용자 검색하기

**As a** 워크스페이스 멤버  
**I want to** 다른 사용자를 검색할 수 있다  
**So that** 팀원을 초대하거나 협업할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 멤버 초대 페이지에 있다  
**When** username 또는 displayName을 입력한다  
**And** "검색" 버튼을 클릭한다  
**Then** 검색 결과가 표시된다

#### 비즈니스 규칙
- username과 displayName 모두에서 검색 가능하다
- 검색은 부분 일치로 동작한다
- 이미 워크스페이스 멤버인 사용자는 검색 결과에서 제외된다
- 검색 결과는 최대 10개까지 표시된다

#### 테스트 시나리오
1. **username 검색**: username으로 사용자 검색
2. **displayName 검색**: displayName으로 사용자 검색
3. **부분 일치 검색**: 일부 텍스트로 검색
4. **기존 멤버 제외**: 이미 멤버인 사용자 검색 결과에서 제외 확인
5. **검색 결과 제한**: 10개 초과 결과 처리 확인
