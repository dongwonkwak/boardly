# US-402-003: 실시간 동기화

**As a** 팀원  
**I want to** 다른 멤버가 수정한 내용을 실시간으로 확인하여  
**So that** 동시 작업 충돌을 피할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 실시간 카드 이동 동기화**
```gherkin
Given 두 명의 사용자가 같은 보드를 보고 있을 때
When 한 사용자가 카드를 다른 리스트로 이동하면
Then 다른 사용자의 화면에 카드 이동이 즉시 반영되고
And 부드러운 애니메이션으로 변경사항이 표시된다
```

**✅ 성공 케이스 - 실시간 편집 상태 표시**
```gherkin
Given 사용자가 카드를 편집하고 있을 때
When 다른 사용자가 같은 보드를 보면
Then 편집 중인 카드에 "편집 중" 표시가 나타나고
And 편집자의 이름이 표시된다
```

**✅ 성공 케이스 - 동시 편집 충돌 처리**
```gherkin
Given 두 사용자가 같은 카드를 동시에 편집할 때
When 한 사용자가 먼저 저장하면
Then 나중에 저장하려는 사용자에게 충돌 알림이 표시되고
And 최신 버전을 확인하고 다시 편집할 수 있는 옵션이 제공된다
```

**Priority:** Medium | **Story Points:** 10
