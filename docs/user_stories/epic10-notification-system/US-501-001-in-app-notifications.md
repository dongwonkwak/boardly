# US-501-001: 인앱 알림

**As a** 사용자  
**I want to** 나와 관련된 중요한 변경 사항을 놓치지 않고 알림을 받고  
**So that** 적시에 대응할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 담당자 할당 알림**
```gherkin
Given 사용자가 카드의 담당자로 할당되었을 때
When 할당이 완료되면
Then 인앱 알림이 즉시 표시되고
And 알림 센터에 알림이 추가되고
And 알림을 클릭하면 해당 카드로 이동한다
```

**✅ 성공 케이스 - 댓글 멘션 알림**
```gherkin
Given 사용자가 댓글에서 멘션(@사용자명)되었을 때
When 댓글이 작성되면
Then 실시간 알림이 표시되고
And 알림 아이콘에 새 알림 배지가 표시되고
And 해당 댓글로 바로 이동할 수 있다
```

**✅ 성공 케이스 - 마감일 임박 알림**
```gherkin
Given 사용자가 담당자로 할당된 카드의 마감일이 24시간 이내로 임박했을 때
When 시스템이 마감일을 체크하면
Then 마감일 임박 알림이 표시되고
And 카드 제목과 남은 시간이 표시되고
And 카드로 바로 이동할 수 있는 링크가 제공된다
```

**✅ 성공 케이스 - 알림 읽음 처리**
```gherkin
Given 사용자가 읽지 않은 알림을 가지고 있을 때
When 알림을 클릭하거나 알림 센터에서 확인하면
Then 해당 알림이 읽음 상태로 변경되고
And 알림 배지의 개수가 감소한다
```

**Priority:** Medium | **Story Points:** 6
