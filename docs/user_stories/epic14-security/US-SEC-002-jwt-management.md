# US-SEC-002: JWT 토큰 관리 `[P0]`

**As a** 사용자  
**I want to** 세션이 안전하게 관리되고  
**So that** 적절한 시점에 재인증을 요구받고 싶다.

## Scenarios

### ✅ 성공 케이스 - 안전한 토큰 발급
```gherkin
Given 사용자가 성공적으로 로그인했을 때
When JWT 토큰이 발급되면
Then 토큰에 사용자 ID, 발급 시간, 만료 시간이 포함되고
And 강력한 비밀키로 서명되고
And 토큰 만료 시간이 적절히 설정된다 (예: 24시간)
```

### ✅ 성공 케이스 - 토큰 만료 처리
```gherkin
Given 사용자의 JWT 토큰이 만료되었을 때
When 보호된 리소스에 접근하려고 시도하면
Then 401 Unauthorized 응답이 반환되고
And "세션이 만료되었습니다. 다시 로그인해주세요" 메시지가 표시되고
And 로그인 페이지로 자동 리다이렉트된다
```

### ✅ 성공 케이스 - 토큰 자동 갱신
```gherkin
Given 사용자가 활발히 서비스를 이용하고 있고
And 토큰 만료가 임박했을 때 (예: 1시간 전)
When API 요청을 보내면
Then 새로운 토큰이 자동으로 발급되고
And 기존 토큰이 무효화되고
And 사용자는 중단 없이 서비스를 계속 이용할 수 있다
```

### ❌ 실패 케이스 - 위조된 토큰 거부
```gherkin
Given 공격자가 위조된 JWT 토큰으로 접근을 시도할 때
When 서버에서 토큰을 검증하면
Then 서명 검증 실패로 토큰이 거부되고
And 403 Forbidden 응답이 반환되고
And 보안 로그에 의심 활동이 기록된다
```

**Priority:** High | **Story Points:** 6
