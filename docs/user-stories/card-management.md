# 카드 관리 유저스토리

## Epic: 카드 관리
**목표**: 사용자가 보드 내에서 카드를 생성하고 관리할 수 있다.

---

## User Story 1: 카드 추가하기

**As a** 사용자  
**I want to** 새로운 카드를 추가할 수 있다  
**So that** 할 일이나 작업을 체계적으로 관리할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 보드 페이지에 있다  
**When** 리스트 하단의 "카드 추가" 버튼을 클릭한다  
**Then** 카드 추가 입력 필드가 나타난다

**Given** 카드 추가 입력 필드가 나타났다  
**When** 카드 제목을 입력한다  
**And** Enter 키를 누르거나 "추가" 버튼을 클릭한다  
**Then** 새로운 카드가 해당 리스트에 추가된다  
**And** 입력 필드가 초기화된다

#### 비즈니스 규칙
- 카드 제목은 필수 입력 항목이다
- 카드 제목은 1-200자 사이여야 한다
- 새로 생성된 카드는 리스트의 맨 아래에 추가된다
- 카드는 생성 시 "할 일" 리스트에 기본적으로 추가된다

#### 예외 상황
**Given** 카드 추가 입력 필드가 나타났다  
**When** 제목 없이 Enter 키를 누른다  
**Then** 카드가 생성되지 않는다

**Given** 카드 추가 입력 필드가 나타났다  
**When** 제목을 200자를 초과하여 입력한다  
**And** Enter 키를 누른다  
**Then** "제목은 200자 이하여야 합니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 추가**: 제목 입력 후 카드 추가
2. **제목 누락**: 제목 없이 추가 시도
3. **제목 길이 초과**: 200자 초과 제목 입력
4. **빈 공백 제목**: 공백만 입력하여 추가 시도
5. **특수 문자 포함**: 특수 문자가 포함된 제목으로 카드 추가

## User Story 2: 카드 이동하기

**As a** 사용자  
**I want to** 카드를 다른 리스트로 이동시킬 수 있다  
**So that** 작업 진행 상황을 시각적으로 관리할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 보드 페이지에 있다  
**When** 카드를 드래그한다  
**And** 다른 리스트로 드롭한다
**Then** 카드가 해당 리스트로 이동한다

**Given** 사용자가 보드 페이지에 있다  
**When** 카드를 클릭하여 상세 모달을 연다  
**And** "리스트 이동" 드롭다운을 선택한다
**And** 목적지 리스트를 선택한다
**Then** 카드가 선택한 리스트로 이동한다

#### 비즈니스 규칙
- 카드는 같은 보드 내의 다른 리스트로만 이동 가능하다
- 이동된 카드는 목적지 리스트의 맨 아래에 추가된다
- 카드 이동 시 이전 위치 정보가 히스토리에 기록된다
- 카드 이동은 실시간으로 다른 팀원에게 반영된다

#### 예외 상황
**Given** 사용자가 카드를 드래그하고 있다  
**When** 보드 외부로 드롭한다  
**Then** 카드가 원래 위치로 돌아간다

**Given** 사용자가 카드를 드래그하고 있다  
**When** 권한이 없는 리스트로 드롭한다  
**Then** "이동할 권한이 없습니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **드래그 앤 드롭**: 카드를 다른 리스트로 드래그하여 이동
2. **모달을 통한 이동**: 카드 상세 모달에서 리스트 변경
3. **권한 확인**: 권한이 없는 리스트로 이동 시도
4. **실시간 동기화**: 다른 사용자의 카드 이동이 실시간으로 반영
5. **히스토리 기록**: 카드 이동 이력이 정확히 기록됨

## User Story 3: 카드 상세 정보 보기

**As a** 사용자  
**I want to** 카드의 상세 정보를 볼 수 있다  
**So that** 카드에 대한 자세한 정보를 확인하고 편집할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 보드 페이지에 있다  
**When** 카드를 클릭한다  
**Then** 카드 상세 모달이 열린다

**Given** 카드 상세 모달이 열려있다  
**Then** 카드 제목, 설명, 담당자, 마감일, 라벨, 체크리스트, 댓글 등의 정보가 표시된다

#### 비즈니스 규칙
- 카드 상세 모달은 ESC 키나 X 버튼으로 닫을 수 있다
- 카드 상세 정보는 실시간으로 저장된다
- 카드 상세 모달 외부 클릭 시 모달이 닫힌다

#### 테스트 시나리오
1. **모달 열기**: 카드 클릭 시 상세 모달 표시
2. **모달 닫기**: ESC 키, X 버튼, 외부 클릭으로 모달 닫기
3. **실시간 저장**: 정보 변경 시 자동 저장 확인
4. **권한 확인**: 편집 권한이 없는 사용자의 접근 제한
