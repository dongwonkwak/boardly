# Boardly User Stories

## 📋 개요
Boardly 프로젝트의 사용자 스토리를 Epic별로 체계적으로 정리한 문서입니다. 각 스토리는 BDD(Behavior-Driven Development) 방식의 Given-When-Then 형식으로 작성되어 테스트 가능하고 명확한 요구사항을 제시합니다.

---

## 🚀 Phase 0: MVP 필수 기능

### 👤 Epic 1: 사용자 관리

#### US-101-001: 회원가입
**As a** 신규 사용자  
**I want to** 이메일과 비밀번호를 사용하여 계정을 생성하고  
**So that** 서비스를 이용할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 유효한 정보로 회원가입**
```gherkin
Given 사용자가 회원가입 페이지에 있고
And 유효한 이메일 주소를 입력하고
And 8자 이상의 복합 비밀번호를 입력하고
And 1-50자의 한글/영문 성, 이름을 입력했을 때
When 회원가입 버튼을 클릭하면
Then 계정이 성공적으로 생성되고
And 로그인 페이지로 리다이렉트되고
And "회원가입이 완료되었습니다" 메시지가 표시된다
```

**❌ 실패 케이스 - 이메일 중복**
```gherkin
Given 사용자가 회원가입 페이지에 있고
And 이미 등록된 이메일 주소를 입력했을 때
When 회원가입 버튼을 클릭하면
Then "이미 사용 중인 이메일입니다" 오류 메시지가 표시되고
And 회원가입이 진행되지 않는다
```

**❌ 실패 케이스 - 비밀번호 복잡도 미충족**
```gherkin
Given 사용자가 회원가입 페이지에 있고
And 8자 미만이거나 대소문자/특수문자가 없는 비밀번호를 입력했을 때
When 회원가입 버튼을 클릭하면
Then "비밀번호는 8자 이상, 대소문자 및 특수문자를 포함해야 합니다" 오류 메시지가 표시되고
And 회원가입이 진행되지 않는다
```

**Priority:** High | **Story Points:** 5

#### US-101-002: 로그인
**As a** 가입한 사용자  
**I want to** 내 계정으로 로그인하여  
**So that** 개인화된 서비스를 이용할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 올바른 인증 정보로 로그인**
```gherkin
Given 사용자가 로그인 페이지에 있고
And 등록된 이메일과 올바른 비밀번호를 입력했을 때
When 로그인 버튼을 클릭하면
Then JWT 토큰이 발급되고
And 로컬 스토리지에 토큰이 저장되고
And 대시보드 페이지로 리다이렉트된다
```

**❌ 실패 케이스 - 잘못된 인증 정보**
```gherkin
Given 사용자가 로그인 페이지에 있고
And 존재하지 않는 이메일 또는 잘못된 비밀번호를 입력했을 때
When 로그인 버튼을 클릭하면
Then "이메일 또는 비밀번호가 올바르지 않습니다" 오류 메시지가 표시되고
And 로그인이 진행되지 않는다
```

**Priority:** High | **Story Points:** 3

---

#### US-101-003: 로그아웃
**As a** 로그인된 사용자  
**I want to** 안전하게 세션을 종료하여  
**So that** 내 계정을 보호할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 로그아웃 수행**
```gherkin

Then JWT 토큰이 로컬 스토리지에서 삭제되고
And 랜딩 페이지로 리다이렉트되고
And 보호된 페이지에 접근할 수 없게 된다
```

**Priority:** High | **Story Points:** 2

**So that** 계정 상태를 파악할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 프로필 정보 조회**

#### US-101-005: 프로필 수정
**As a** 사용자  
**I want to** 내 프로필 정보를 수정하여  
**So that** 최신 정보를 유지할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 프로필 정보 수정**

**❌ 실패 케이스 - 유효하지 않은 입력**

```gherkin
When 저장 버튼을 클릭하면
Then "성과 이름은 1-50자 사이여야 합니다" 오류 메시지가 표시되고
And 프로필 업데이트가 진행되지 않는다
```

**Priority:** Medium | **Story Points:** 3


**❌ 실패 케이스 - 새 비밀번호 복잡도 미충족**
```gherkin
Given 사용자가 비밀번호 변경 페이지에 있고
And 올바른 현재 비밀번호를 입력하고
And 복잡도 요구사항을 충족하지 않는 새 비밀번호를 입력했을 때
When 변경 버튼을 클릭하면
Then "새 비밀번호는 8자 이상, 대소문자 및 특수문자를 포함해야 합니다" 오류 메시지가 표시되고
And 비밀번호 변경이 진행되지 않는다
```

### 🏢 Epic 2: 워크스페이스 관리

#### US-150-001: 워크스페이스 생성
**As a** 사용자  
**I want to** 개인 프로젝트와 팀 프로젝트를 분리하여 관리하기 위해 별도의 워크스페이스를 만들고  
**So that** 프로젝트를 체계적으로 구분할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - Personal 워크스페이스 생성**
```gherkin
Given 사용자가 대시보드에 있고
And 사용자당 워크스페이스 수가 10개 미만일 때
When 워크스페이스 생성 버튼을 클릭하고
And 워크스페이스 이름을 입력하고
And Personal 타입을 선택하고
And 생성 버튼을 클릭하면
Then 새로운 Personal 워크스페이스가 생성되고
And 워크스페이스 목록에 표시되고
And "워크스페이스가 성공적으로 생성되었습니다" 메시지가 표시된다
```

**✅ 성공 케이스 - Team 워크스페이스 생성**
```gherkin
Given 사용자가 대시보드에 있고
And 사용자당 워크스페이스 수가 10개 미만일 때
When 워크스페이스 생성 버튼을 클릭하고
And 워크스페이스 이름을 입력하고
And Team 타입을 선택하고
And 생성 버튼을 클릭하면
Then 새로운 Team 워크스페이스가 생성되고
And 워크스페이스 목록에 표시되고
And 멤버 초대 기능이 활성화된다
```

**❌ 실패 케이스 - 워크스페이스 수 제한 초과**
```gherkin
Given 사용자가 이미 10개의 워크스페이스를 가지고 있고
When 새로운 워크스페이스를 생성하려고 시도하면
Then "워크스페이스는 최대 10개까지 생성할 수 있습니다" 오류 메시지가 표시되고

```

**❌ 실패 케이스 - 빈 워크스페이스 이름**
```gherkin
Given 사용자가 워크스페이스 생성 모달에 있고
And 워크스페이스 이름을 입력하지 않았을 때
When 생성 버튼을 클릭하면
Then "워크스페이스 이름을 입력해주세요" 오류 메시지가 표시되고
And 워크스페이스 생성이 진행되지 않는다
```

**Priority:** High | **Story Points:** 5

#### US-150-002: 워크스페이스 관리
**As a** 워크스페이스 소유자  
**I want to** 내 워크스페이스의 정보를 관리하고

```gherkin
When 저장 버튼을 클릭하면
Then 워크스페이스 정보가 업데이트되고
```

```gherkin
And 워크스페이스에 1개 이상의 보드가 있을 때
When 워크스페이스 삭제를 시도하면
Then "워크스페이스를 삭제하려면 먼저 모든 보드를 삭제해주세요" 오류 메시지가 표시되고
And 워크스페이스 삭제가 진행되지 않는다
```

**❌ 실패 케이스 - 권한이 없는 사용자의 수정 시도**
```gherkin
Given 사용자가 워크스페이스 소유자가 아니고
When 워크스페이스 정보를 수정하려고 시도하면
Then "워크스페이스를 수정할 권한이 없습니다" 오류 메시지가 표시되고
And 수정이 진행되지 않는다
```

**Priority:** High | **Story Points:** 4
