# US-202-001: 리스트 생성 `[P0]`

**As a** 사용자  
**I want to** 내 업무 흐름에 맞게 '아이디어', '디자인 중', '개발 중', '완료' 같은 리스트를 만들고  
**So that** 작업 단계를 명확히 구분할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 리스트 생성
```gherkin
Given 사용자가 보드에 접근하고
And 보드당 리스트 수가 20개 미만이고
And 사용자가 'content:write' 권한을 가지고 있을 때
When 리스트 추가 버튼을 클릭하고
And 리스트 이름을 입력하고
And 선택적으로 색상을 선택하고
And 생성 버튼을 클릭하면
Then 새로운 리스트가 보드 우측에 추가되고
And 리스트가 지정된 색상으로 표시되고
And 자동으로 순서(position)가 할당되고
And "리스트가 생성되었습니다" 메시지가 표시되고
And 활동 내역에 "리스트 생성" 기록이 남는다
```

### ❌ 실패 케이스 - 리스트 수 제한 초과
```gherkin
Given 보드에 이미 20개의 리스트가 있을 때
When 새로운 리스트를 생성하려고 시도하면
Then HTTP 422 Unprocessable Entity 응답이 반환되고
And "보드당 최대 20개의 리스트만 생성할 수 있습니다" 오류 메시지가 표시되고
And 리스트 생성이 진행되지 않는다
```

### ❌ 실패 케이스 - 빈 리스트 이름
```gherkin
Given 사용자가 리스트 생성 모달에 있고
And 리스트 이름을 입력하지 않았을 때
When 생성 버튼을 클릭하면
Then HTTP 400 Bad Request 응답이 반환되고
And "리스트 이름을 입력해주세요" 오류 메시지가 표시되고
And 리스트 생성이 진행되지 않는다
```

### ❌ 실패 케이스 - 권한 없는 사용자의 리스트 생성 시도
```gherkin
Given 사용자가 'content:write' 권한이 없을 때
When 리스트 생성을 시도하면
Then HTTP 403 Forbidden 응답이 반환되고
And "리스트를 생성할 권한이 없습니다" 오류 메시지가 표시되고
And 리스트 생성이 진행되지 않는다
```

**Priority:** High | **Story Points:** 4
