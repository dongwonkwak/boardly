# US-DELETE-001: 워크스페이스 안전 삭제 `[P0]`

**As a** 워크스페이스 소유자  
**I want to** 실수로 워크스페이스를 삭제하는 것을 방지하고  
**So that** 중요한 데이터를 안전하게 보호할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 빈 워크스페이스 삭제
```gherkin
Given 사용자가 워크스페이스 소유자이고
And 워크스페이스에 보드가 없을 때
When 워크스페이스 삭제를 시도하고
And 확인 대화상자에서 워크스페이스 이름을 정확히 입력하면
Then 워크스페이스가 완전히 삭제되고
And 대시보드로 리다이렉트되고
And "워크스페이스가 삭제되었습니다" 메시지가 표시된다
```

### ❌ 실패 케이스 - 보드가 있는 워크스페이스 삭제 시도
```gherkin
Given 사용자가 워크스페이스 소유자이고
And 워크스페이스에 1개 이상의 보드가 있을 때
When 워크스페이스 삭제를 시도하면
Then "워크스페이스를 삭제하려면 먼저 모든 보드를 삭제해주세요" 오류 메시지가 표시되고
And 현재 보드 목록이 표시되고
And 워크스페이스 삭제가 진행되지 않는다
```

### ❌ 실패 케이스 - 잘못된 워크스페이스 이름 입력
```gherkin
Given 사용자가 워크스페이스 삭제 확인 대화상자에 있을 때
When 워크스페이스 이름과 다른 텍스트를 입력하면
Then "워크스페이스 이름이 일치하지 않습니다" 오류 메시지가 표시되고
And 삭제 버튼이 비활성화 상태를 유지한다
```

**Priority:** High | **Story Points:** 5
