# US-006 카드 상세 (설명/댓글/라벨/마감일) (F-301, P0)

## 배경
카드 상세는 업무 맥락을 공유하고 실행 가능성을 높이는 핵심 화면이다. 설명(마크다운), 댓글, 라벨, 마감일을 통해 협업 정보를 구조화한다.

참조: `PRD.md` F-301, `SRS.md` 3.7, `story_map.md` 6번 백본

## 사용자 스토리
- (설명) 나는 사용자로서, 카드의 상세 설명을 마크다운으로 작성·편집하고 싶다.
- (댓글) 나는 팀원으로서, 카드에 댓글을 추가/수정/삭제하며 논의 기록을 남기고 싶다.
- (라벨) 나는 사용자로서, 카드에 라벨을 추가·제거하여 성격/우선순위를 표시하고 싶다.
- (마감일) 나는 사용자로서, 카드의 마감일을 설정·완료 처리하여 기한을 관리하고 싶다.

## 수용 기준 (Acceptance Criteria)
1. 설명(마크다운)
   - 마크다운 입력/미리보기/저장이 가능하다.
   - 저장 후 새로고침 시 내용이 유지된다.
2. 댓글
   - 생성/수정/삭제 가능. 작성자만 수정/삭제 가능.
   - 타임스탬프와 작성자 정보가 표시된다.
3. 라벨
   - 보드 차원의 라벨을 생성/관리하고 카드를 라벨과 연결/해제할 수 있다.
   - 라벨 색상/이름은 보드 내에서 고유하다(정책 기준).
4. 마감일
   - 날짜/시간 설정, 완료 체크/해제 가능.
   - 완료 시 `completedAt` 저장, 미완료로 되돌릴 수 있다.

## 비기능 (NFR)
- 반응속도 ≤ 0.5초, 로딩 ≤ 2초
- 권한: JWT 인증, 보드 접근 권한 검증
- 보안: XSS 방지(마크다운 렌더링 시 sanitize)

## 테스트 시나리오 (샘플)
- 설명 작성/수정 → 저장 후 재로딩 유지, XSS 차단 확인
- 댓글 CRUD → 작성자 제약 준수, 타임스탬프 표시
- 라벨 연결/해제 → UI 배지 반영, 필터에서 검색 가능(선택)
- 마감일 설정/완료/해제 → 상태/타임스탬프 저장 확인

## 범위
- 포함(P0): 설명, 댓글, 라벨, 마감일
- 제외(P1): 담당자, 첨부파일, 체크리스트(별도 스토리)
