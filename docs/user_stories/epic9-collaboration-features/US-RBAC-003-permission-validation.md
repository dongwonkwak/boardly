# US-RBAC-003: 권한 검증 시스템 `[P0]`

**As a** 사용자  
**I want to** 내 권한에 맞지 않는 작업은 차단되어  
**So that** 시스템이 안전하게 보호되기를 원한다.

## Scenarios

### ✅ 성공 케이스 - API 레벨 권한 검증
```gherkin
Given 사용자가 API 요청을 보낼 때
When 요청이 서버에 도달하면
Then JWT 토큰이 검증되고
And 사용자 ID가 추출되고
And 요청된 리소스에 대한 사용자 권한이 확인되고
And 권한이 있는 경우에만 요청이 처리된다
```

### ✅ 성공 케이스 - 권한 우선순위 적용
```gherkin
Given 사용자가 워크스페이스 소유자이면서 특정 보드의 뷰어일 때
When 해당 보드에 접근하면
Then 워크스페이스 소유자 권한이 우선 적용되고
And 보드에 대한 모든 권한을 가지게 되고
And 보드 뷰어 권한은 무시된다
```

### ✅ 성공 케이스 - 동적 권한 확인
```gherkin
Given 사용자의 역할이 변경되었을 때
When 다음 API 요청을 보내면
Then 최신 권한 정보가 데이터베이스에서 조회되고
And 변경된 권한이 즉시 반영되고
And 권한 변경 이력이 로그에 기록된다
```

**Priority:** High | **Story Points:** 5
