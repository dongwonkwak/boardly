# US-011 알림: 인앱 및 개인 알림 센터 (F-501, F-603, P1)

## 배경
사용자는 자신과 관련된 중요한 변화를 놓치지 않기 위해 인앱 알림과 개인 알림 센터가 필요하다.

참조: `PRD.md` F-501/F-603, `SRS.md` 3.4.4, 3.9, `story_map.md` 8번 백본(P1)

## 사용자 스토리
- (인앱) 나는 사용자로서, 담당자 지정/댓글 멘션/마감 임박/초대/역할 변경 등의 이벤트를 즉시 알림으로 받고 싶다.
- (센터) 나는 사용자로서, 나에게만 중요한 알림을 모아보고 읽음 처리하고 싶다.
- (권한 관련) 나는 사용자로서, 권한 변경이나 초대 관련 알림을 통해 보안 상태를 파악하고 싶다.

## 수용 기준 (Acceptance Criteria)
1. 인앱 알림
   - 주요 이벤트 발생 시 실시간 또는 준실시간으로 배지/토스트/패널 표시.
   - 클릭 시 관련 리소스로 이동.
   - 권한 관련 이벤트: 초대, 역할 변경, 권한 충돌 등 포함.
2. 개인 알림 센터
   - 알림 목록, 읽음/모두 읽음 처리, 유형별 필터/정렬 제공.
   - 권한 관련 알림 별도 분류 및 강조 표시.
3. 설정(선택)
   - 알림 유형별 수신 설정 토글 제공.
   - 권한 관련 알림 우선순위 설정.

## 비기능 (NFR)
- 지연 ≤ 3초(준실시간), 대량 이벤트 처리 안정성
- 보안: 사용자별 격리, 권한 검증

## 테스트 시나리오 (샘플)
- 담당자 지정 → 인앱 알림 표시, 클릭 이동
- 초대 수락/거부 → 인앱 알림 표시
- 역할 변경 → 인앱 알림 표시, 권한 관련 분류
- 알림 센터 읽음 처리 → 배지 감소
- 필터: 미읽음만 보기, 권한 관련만 보기 동작

## 범위
- 포함(P1): 인앱 알림, 개인 알림 센터
- 제외: 이메일/푸시(확장)
