# US-203-003: 카드 이동

**As a** 사용자  
**I want to** 업무 상황 변화에 따라 카드를 쉽게 다른 단계로 옮기고  
**So that** 작업 진행 상황을 실시간으로 반영할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 같은 리스트 내 카드 순서 변경**
```gherkin
Given 사용자가 보드에 있고
And 리스트에 2개 이상의 카드가 있을 때
When 카드를 드래그하여 같은 리스트 내 다른 위치로 이동하고
And 드롭하면
Then 카드가 새로운 위치로 이동하고
And 다른 카드들의 순서가 자동으로 조정되고
And 활동 내역에 기록된다
```

**✅ 성공 케이스 - 다른 리스트로 카드 이동**
```gherkin
Given 사용자가 보드에 있고
And 2개 이상의 리스트가 있고
And 대상 리스트의 카드 수가 100개 미만일 때
When 카드를 드래그하여 다른 리스트로 이동하고
And 드롭하면
Then 카드가 새로운 리스트로 이동하고
And 이전 리스트에서 제거되고
And 활동 내역에 "카드 이동" 기록이 남는다
```

**❌ 실패 케이스 - 카드 수 제한으로 인한 이동 실패**
```gherkin
Given 사용자가 카드를 다른 리스트로 이동하려고 하고
And 대상 리스트에 이미 100개의 카드가 있을 때
When 카드를 해당 리스트로 드롭하면
Then "대상 리스트의 카드 수 제한을 초과했습니다" 오류 메시지가 표시되고
And 카드가 원래 위치로 되돌아간다
```

**Priority:** High | **Story Points:** 6
