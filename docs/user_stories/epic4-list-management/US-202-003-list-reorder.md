# US-202-003: 리스트 순서 변경 `[P0]`

**As a** 사용자  
**I want to** 워크플로우 변화에 따라 리스트의 순서를 쉽게 조정하고  
**So that** 업무 흐름을 최적화할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 드래그 앤 드롭으로 리스트 순서 변경
```gherkin
Given 사용자가 보드에 있고
And 2개 이상의 리스트가 존재하고
And 사용자가 'content:write' 권한을 가지고 있을 때
When 리스트 헤더를 드래그하여 다른 위치로 이동하고
And 드롭하면
Then 리스트가 새로운 위치로 이동하고
And 다른 리스트들의 position이 자동으로 조정되고
And 변경사항이 즉시 반영되고
And 활동 내역에 "리스트 이동" 기록이 남는다
```

### ✅ 성공 케이스 - 리스트 순서 변경 시각적 피드백
```gherkin
Given 사용자가 리스트를 드래그하고 있을 때
When 드래그 중에 다른 리스트 위로 이동하면
Then 드롭 가능한 위치가 시각적으로 표시되고
And 드래그 중인 리스트가 반투명하게 표시되고
And 드롭 가이드라인이 표시된다
```

### ❌ 실패 케이스 - 권한 없는 사용자의 리스트 이동 시도
```gherkin
Given 사용자가 'content:write' 권한이 없을 때
When 리스트를 드래그하여 이동하려고 시도하면
Then 드래그가 시작되지 않고
And "리스트를 이동할 권한이 없습니다" 툴팁이 표시된다
```

**Priority:** Medium | **Story Points:** 5
