# US-DELETE-002: 보드 휴지통 시스템 `[P0]`

**As a** 사용자  
**I want to** 실수로 삭제한 보드를 일정 기간 내에 복구할 수 있기를 원하고  
**So that** 데이터 손실 위험을 최소화할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 보드 소프트 삭제
```gherkin
Given 사용자가 보드 소유자이고
And 보드 설정 페이지에 있을 때
When 삭제 버튼을 클릭하고
And 확인 대화상자에서 삭제를 확인하면
Then 보드가 휴지통으로 이동되고
And 30일 후 자동 삭제 스케줄이 설정되고
And "보드가 휴지통으로 이동되었습니다. 30일 후 영구 삭제됩니다" 메시지가 표시되고
And 모든 멤버의 보드 접근이 즉시 차단된다
```

### ✅ 성공 케이스 - 휴지통에서 보드 복구
```gherkin
Given 사용자가 휴지통에 있는 보드를 소유하고 있을 때
When 휴지통에서 보드를 선택하고 복구 버튼을 클릭하면
Then 보드가 원래 워크스페이스로 복구되고
And 모든 리스트와 카드가 그대로 복원되고
And 멤버들의 접근 권한이 복구되고
And "보드가 성공적으로 복구되었습니다" 메시지가 표시된다
```

### ✅ 성공 케이스 - 휴지통에서 보드 영구 삭제
```gherkin
Given 사용자가 휴지통에 있는 보드를 소유하고 있을 때
When 영구 삭제 버튼을 클릭하고
And 보드 이름을 재입력하여 확인하면
Then 보드와 모든 관련 데이터가 영구 삭제되고
And "보드가 영구적으로 삭제되었습니다" 메시지가 표시된다
```

### ✅ 성공 케이스 - 30일 후 자동 영구 삭제
```gherkin
Given 보드가 휴지통에 30일간 있었을 때
When 시스템이 자동 삭제 스케줄을 실행하면
Then 해당 보드와 모든 관련 데이터가 자동으로 영구 삭제되고
And 더 이상 복구할 수 없게 된다
```

**Priority:** High | **Story Points:** 7
