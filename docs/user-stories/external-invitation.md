# 외부 초대 유저스토리

## Epic: 외부 초대
**목표**: 외부 사용자나 내부 사용자에게 워크스페이스 또는 특정 보드에 초대하여 협업할 수 있다.

---

## User Story 1: 워크스페이스 초대하기

**As a** 워크스페이스 ADMIN  
**I want to** 외부 사용자나 내부 사용자를 워크스페이스에 초대할 수 있다  
**So that** 팀 협업을 위한 멤버를 추가할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 워크스페이스 설정 페이지에 있다  
**When** "멤버 초대" 버튼을 클릭한다  
**Then** 워크스페이스 초대 모달이 표시된다

**Given** 워크스페이스 초대 모달이 열려있다  
**When** 이메일 주소를 입력한다  
**And** 워크스페이스 권한을 선택한다 (ADMIN/MEMBER)  
**And** "초대 보내기" 버튼을 클릭한다  
**Then** 초대 링크가 생성되고 이메일이 발송된다  
**And** "초대가 발송되었습니다" 메시지가 표시된다

#### 비즈니스 규칙
- 워크스페이스 ADMIN만 외부 사용자를 초대할 수 있다
- 초대 시 워크스페이스 권한(ADMIN/MEMBER)을 지정할 수 있다
- 초대받은 사용자는 해당 워크스페이스의 WORKSPACE 공개 보드에 MEMBER 권한으로 접근 가능하다
- 초대받은 사용자는 해당 워크스페이스의 PUBLIC 보드에 VIEWER 권한으로 접근 가능하다
- PRIVATE 보드는 별도 보드별 초대가 필요하다
- 초대 링크는 7일간 유효하다 (기본값)

#### 예외 상황
**Given** 워크스페이스 초대 모달이 열려있다  
**When** 잘못된 이메일 형식을 입력한다  
**And** "초대 보내기" 버튼을 클릭한다  
**Then** "올바른 이메일 형식을 입력해주세요" 오류 메시지가 표시된다

**Given** 워크스페이스 초대 모달이 열려있다  
**When** 이미 워크스페이스 멤버인 이메일을 입력한다  
**And** "초대 보내기" 버튼을 클릭한다  
**Then** "이미 워크스페이스 멤버인 사용자입니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 초대**: 올바른 이메일로 워크스페이스 초대
2. **잘못된 이메일**: 잘못된 형식의 이메일 입력
3. **중복 초대**: 이미 워크스페이스 멤버인 사용자 재초대 시도
4. **권한 확인**: ADMIN이 아닌 사용자의 초대 시도
5. **초대 만료**: 7일 후 초대 링크 만료 확인
6. **WORKSPACE 공개 보드 접근**: 초대받은 사용자의 WORKSPACE 공개 보드 MEMBER 권한 접근 확인
7. **PUBLIC 보드 접근**: 초대받은 사용자의 PUBLIC 보드 VIEWER 권한 접근 확인
8. **PRIVATE 보드 접근 제한**: 초대받은 사용자의 PRIVATE 보드 접근 제한 확인

## User Story 2: 보드 초대하기

**As a** 보드 ADMIN  
**I want to** 외부 사용자나 내부 사용자를 특정 보드에 초대할 수 있다  
**So that** 협업이 필요한 사람들과 보드를 공유할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 보드 페이지에 있다  
**When** "멤버 초대" 버튼을 클릭한다  
**Then** 보드 초대 모달이 표시된다

**Given** 보드 초대 모달이 열려있다  
**When** 이메일 주소를 입력한다  
**And** 보드 권한을 선택한다 (ADMIN/MEMBER/VIEWER)  
**And** "초대 보내기" 버튼을 클릭한다  
**Then** 초대 링크가 생성되고 이메일이 발송된다  
**And** "초대가 발송되었습니다" 메시지가 표시된다

#### 비즈니스 규칙
- 보드 ADMIN만 외부 사용자를 초대할 수 있다
- 모든 공개 범위의 보드에서 초대 가능 (PRIVATE, WORKSPACE, PUBLIC)
- 초대 시 보드 권한(ADMIN/MEMBER/VIEWER)을 지정할 수 있다
- 초대받은 사용자는 해당 보드가 속한 워크스페이스 권한이 없다
- 초대 링크는 7일간 유효하다 (기본값)
- 이미 보드 멤버인 사용자에게 동일한 권한으로 초대 시 "이미 보드 멤버입니다" 메시지 표시
- 이미 보드 멤버인 사용자에게 다른 권한으로 초대 시 권한 변경 확인 후 알림 발송

#### 예외 상황
**Given** 보드 초대 모달이 열려있다  
**When** 잘못된 이메일 형식을 입력한다  
**And** "초대 보내기" 버튼을 클릭한다  
**Then** "올바른 이메일 형식을 입력해주세요" 오류 메시지가 표시된다

**Given** 보드 초대 모달이 열려있다  
**When** 이미 보드 멤버인 이메일을 입력한다  
**And** 동일한 권한을 선택한다  
**And** "초대 보내기" 버튼을 클릭한다  
**Then** "이미 보드 멤버인 사용자입니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 초대**: 올바른 이메일로 보드 초대
2. **잘못된 이메일**: 잘못된 형식의 이메일 입력
3. **중복 초대**: 이미 보드 멤버인 사용자 재초대 시도
4. **권한 확인**: ADMIN이 아닌 사용자의 초대 시도
5. **초대 만료**: 7일 후 초대 링크 만료 확인
6. **PRIVATE 보드 초대**: PRIVATE 보드에 대한 접근 권한 부여를 위한 초대
7. **WORKSPACE 공개 보드 초대**: WORKSPACE 공개 보드에 편집 권한 부여를 위한 초대
8. **PUBLIC 보드 초대**: PUBLIC 보드에 편집 권한 부여를 위한 초대
9. **권한 변경 초대**: 기존 멤버에게 다른 권한으로 초대 시도

## User Story 3: 초대 링크 공유하기

**As a** 워크스페이스 ADMIN 또는 보드 ADMIN  
**I want to** 초대 링크를 복사하여 공유할 수 있다  
**So that** 이메일 외에도 다양한 방법으로 초대할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 워크스페이스 또는 보드 초대 모달에 있다  
**When** "링크 복사" 버튼을 클릭한다  
**Then** 초대 링크가 클립보드에 복사된다  
**And** "링크가 복사되었습니다" 메시지가 표시된다

#### 비즈니스 규칙
- 초대 링크는 워크스페이스별 또는 보드별로 고유하다
- 초대 링크는 만료 기간이 있다
- 링크를 통해 접근한 사용자는 지정된 권한을 받는다

#### 테스트 시나리오
1. **링크 복사**: 초대 링크 클립보드 복사
2. **링크 공유**: 복사된 링크를 다른 채널로 공유
3. **링크 만료**: 만료된 링크 접근 시도

---

## User Story 4: 초대 수락하기

**As a** 초대받은 사용자  
**I want to** 초대를 수락하여 워크스페이스 또는 보드에 접근할 수 있다  
**So that** 협업에 참여할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 초대 링크를 클릭한다  
**When** 회원가입이 필요한 경우 회원가입을 완료한다  
**And** 로그인한다  
**Then** "[초대한 사람]님이 '[워크스페이스/보드 이름]'에 초대했습니다" 환영 팝업이 표시된다  
**And** "바로 가기" 버튼이 제공된다

**Given** 환영 팝업이 표시되어 있다  
**When** "바로 가기" 버튼을 클릭한다  
**Then** 해당 워크스페이스 또는 보드 페이지로 이동한다  
**And** 지정된 권한으로 접근할 수 있다

#### 비즈니스 규칙
- 초대받은 사용자가 회원가입을 하지 않았다면 회원가입이 필수이다
- 워크스페이스 초대를 받은 사용자는 해당 워크스페이스의 WORKSPACE 공개 보드에 MEMBER 권한으로 접근 가능하다
- 워크스페이스 초대를 받은 사용자는 해당 워크스페이스의 PUBLIC 보드에 VIEWER 권한으로 접근 가능하다
- 보드 초대를 받은 사용자는 해당 보드가 속한 워크스페이스 권한이 없다
- 로그인 시 초대 알림과 "바로 가기" 버튼을 제공한다

#### 예외 상황
**Given** 사용자가 만료된 초대 링크를 클릭한다  
**When** 링크에 접근하려고 한다  
**Then** "초대 링크가 만료되었습니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 수락**: 초대 링크를 통한 정상적인 접근
2. **회원가입**: 비회원 사용자의 회원가입 후 초대 수락
3. **링크 만료**: 만료된 초대 링크 접근 시도
4. **권한 확인**: 지정된 권한으로 접근 확인
5. **워크스페이스 초대 수락**: 워크스페이스 초대 수락 후 WORKSPACE 공개 보드 접근
6. **보드 초대 수락**: 보드 초대 수락 후 해당 보드 접근

## User Story 5: 게스트 워크스페이스 관리하기

**As a** 초대받은 사용자  
**I want to** 초대받은 보드 목록을 확인할 수 있다  
**So that** 참여 중인 모든 보드를 관리할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 메인 대시보드에 있다  
**When** "게스트 워크스페이스" 섹션을 확인한다  
**Then** 초대받은 보드 목록이 표시된다

**Given** 게스트 워크스페이스에 보드 목록이 표시되어 있다  
**When** 특정 보드를 클릭한다  
**Then** 해당 보드 페이지로 이동한다

#### 비즈니스 규칙
- 메인 대시보드에 "게스트 워크스페이스" 섹션이 존재한다
- 초대받은 보드 목록이 시간순으로 정렬되어 표시된다
- 보드별로 권한 정보가 표시된다
- 워크스페이스 초대를 받은 사용자는 해당 워크스페이스의 WORKSPACE 공개 보드도 표시된다
- 워크스페이스 초대를 받은 사용자는 해당 워크스페이스의 PUBLIC 보드도 표시된다

#### 테스트 시나리오
1. **목록 조회**: 초대받은 보드 목록 표시
2. **보드 접근**: 게스트 워크스페이스에서 보드 접근
3. **권한 표시**: 보드별 권한 정보 확인
4. **정렬 확인**: 시간순 정렬 확인
5. **WORKSPACE 공개 보드 표시**: 워크스페이스 초대받은 사용자의 WORKSPACE 공개 보드 표시
6. **PUBLIC 보드 표시**: 워크스페이스 초대받은 사용자의 PUBLIC 보드 표시

## User Story 6: PUBLIC 보드 URL 접근하기

**As a** PUBLIC 보드 URL을 아는 사용자  
**I want to** PUBLIC 보드에 읽기 권한으로 접근할 수 있다  
**So that** 보드 내용을 확인할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 PUBLIC 보드 URL을 가지고 있다  
**When** URL을 클릭하거나 브라우저에 입력한다  
**Then** 해당 보드 페이지가 표시된다  
**And** 읽기 전용 모드로 보드에 접근할 수 있다

**Given** 사용자가 PUBLIC 보드에 접근해 있다  
**When** 편집 기능을 시도한다  
**Then** "로그인이 필요합니다" 또는 "권한이 없습니다" 메시지가 표시된다

#### 비즈니스 규칙
- PUBLIC 보드의 URL을 아는 사용자는 누구나 VIEWER 권한으로 접근 가능하다
- PUBLIC 보드 접근자는 편집, 댓글 작성, 카드 이동 등의 기능을 사용할 수 없다
- PUBLIC 보드 접근자는 로그인하지 않아도 접근 가능하다
- PUBLIC 보드 접근자는 보드의 모든 내용을 볼 수 있다
- 편집 권한이 필요한 경우 보드별 초대가 필요하다

#### 예외 상황
**Given** 사용자가 PRIVATE 또는 WORKSPACE 공개 보드 URL을 가지고 있다  
**When** URL을 클릭하거나 브라우저에 입력한다  
**Then** "접근 권한이 없습니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 접근**: PUBLIC 보드 URL을 통한 정상적인 접근
2. **읽기 전용**: 편집 기능 사용 시도 시 권한 제한 확인
3. **PRIVATE 보드 접근**: PRIVATE 보드 URL 접근 시도 시 권한 거부 확인
4. **WORKSPACE 공개 보드 접근**: WORKSPACE 공개 보드 URL 접근 시도 시 권한 거부 확인
5. **로그인 없이 접근**: 로그인하지 않은 상태에서 PUBLIC 보드 접근

## User Story 7: 워크스페이스 생성하기

**As a** 초대받은 사용자  
**I want to** 자신의 워크스페이스를 생성할 수 있다  
**So that** 자신의 프로젝트를 관리할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 메인 대시보드에 있다  
**When** "워크스페이스 생성" 버튼을 클릭한다  
**Then** 워크스페이스 생성 모달이 표시된다

**Given** 워크스페이스 생성 모달이 열려있다  
**When** 워크스페이스 이름을 입력한다  
**And** 워크스페이스 설명을 입력한다 (선택사항)  
**And** "생성" 버튼을 클릭한다  
**Then** 새로운 워크스페이스가 생성된다  
**And** 생성된 워크스페이스 페이지로 이동한다

#### 비즈니스 규칙
- 워크스페이스 이름은 필수 입력 항목이다
- 워크스페이스 이름은 1-50자 사이여야 한다
- 워크스페이스 설명은 선택사항이며, 최대 200자까지 입력 가능하다
- 워크스페이스를 생성한 사용자는 자동으로 OWNER 역할을 받는다
- 동일한 사용자는 같은 워크스페이스 이름을 가질 수 없다

#### 예외 상황
**Given** 워크스페이스 생성 모달이 열려있다  
**When** 이름 없이 "생성" 버튼을 클릭한다  
**Then** "워크스페이스 이름을 입력해주세요" 오류 메시지가 표시된다

**Given** 워크스페이스 생성 모달이 열려있다  
**When** 이미 존재하는 워크스페이스 이름을 입력한다  
**And** "생성" 버튼을 클릭한다  
**Then** "이미 존재하는 워크스페이스 이름입니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 생성**: 올바른 정보로 워크스페이스 생성
2. **이름 누락**: 이름 없이 생성 시도
3. **중복 이름**: 이미 존재하는 워크스페이스 이름으로 생성 시도
4. **OWNER 권한**: 생성 후 OWNER 권한 확인
