# US-704-001: 검색 및 필터링

**As a** 사용자  
**I want to** 많은 카드 중에서 특정 조건에 맞는 카드만 빠르게 찾고  
**So that** 효율적으로 작업을 관리할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 키워드 검색**
```gherkin
Given 사용자가 보드에 있고
And 여러 카드가 존재할 때
When 검색창에 키워드를 입력하면
Then 제목이나 설명에 해당 키워드가 포함된 카드만 표시되고
And 검색 키워드가 하이라이트되어 표시되고
And 검색 결과 개수가 표시된다
```

**✅ 성공 케이스 - 담당자별 필터링**
```gherkin
Given 사용자가 보드에 있을 때
When 특정 담당자로 필터링하면
Then 해당 담당자가 할당된 카드만 표시되고
And 필터 상태가 UI에 명확히 표시되고
And 필터를 해제할 수 있는 옵션이 제공된다
```

**✅ 성공 케이스 - 라벨별 필터링**
```gherkin
Given 사용자가 보드에 있을 때
When 특정 라벨로 필터링하면
Then 해당 라벨이 적용된 카드만 표시되고
And 선택된 라벨이 시각적으로 강조되어 표시된다
```

**✅ 성공 케이스 - 마감일별 필터링**
```gherkin
Given 사용자가 보드에 있을 때
When 마감일 필터(오늘, 이번 주, 연체 등)를 선택하면
Then 해당 조건에 맞는 카드만 표시되고
And 연체된 카드는 빨간색으로 강조되어 표시된다
```

**✅ 성공 케이스 - 복합 필터링**
```gherkin
Given 사용자가 여러 필터 조건을 설정했을 때 (담당자 + 라벨 + 마감일)
When 필터가 적용되면
Then 모든 조건을 만족하는 카드만 표시되고
And 적용된 모든 필터 조건이 UI에 표시되고
And 개별 필터를 제거할 수 있는 옵션이 제공된다
```

**✅ 성공 케이스 - 검색 결과 없음**
```gherkin
Given 사용자가 검색이나 필터링을 했지만 조건에 맞는 카드가 없을 때
When 검색/필터 결과가 표시되면
Then "검색 결과가 없습니다" 메시지가 표시되고
And 검색 조건을 수정할 수 있는 안내가 제공된다
```

**Priority:** Medium | **Story Points:** 7
