# Epics & Issues — Boardly

프로젝트의 상위 Epic과 Issue를 정의한 문서입니다. Task 단위는 `task-tracker.md`를 참조합니다.

---

## Epic: 사용자 인증/인가 (Project)

### Issue: 로그인 기능 구현 (BRD-101)

* 설명: 사용자가 OAuth2 기반 로그인을 통해 서비스에 접근할 수 있도록 한다.
* 범위:

  * OAuth2 Authorization 요청 엔드포인트 구현
  * OAuth2 Callback 처리 및 토큰 교환
  * 세션/토큰 관리
  * 로그인 성공/실패 리다이렉션 처리
* 참고: 세부 Task는 [Task Tracker](task-tracker.md#issue-로그인-기능-구현-brd-101) 참조

### Issue: 회원가입 기능 구현 (BRD-102)

* 설명: 사용자가 계정을 생성할 수 있도록 회원가입 플로우를 제공한다.
* 범위:

  * 회원가입 API 엔드포인트 구현
  * 유효성 검증 로직 추가
  * 회원가입 완료 처리 (리다이렉션 또는 완료 화면)
* 참고: 세부 Task는 [Task Tracker](task-tracker.md#issue-회원가입-기능-구현-brd-102) 참조

## Epic: 워크스페이스 관리 (예정)

### Issue: 워크스페이스 생성/삭제 (BRD-103)

* 설명: 사용자가 개인/팀 워크스페이스를 생성하고 삭제할 수 있어야 한다.
* 범위:

  * 워크스페이스 생성 API 구현
  * 워크스페이스 삭제 API 구현

### Issue: 워크스페이스 멤버 초대 (BRD-104)

* 설명: 사용자가 다른 사용자를 워크스페이스에 초대할 수 있어야 한다.
* 범위:

  * 초대 API 구현 (PENDING, ACCEPTED, REJECTED 상태 관리)
  * 이메일 초대/링크 초대 지원

---

## Epic: 보드 관리 (예정)

### Issue: 보드 생성/삭제 (BRD-105)

* 설명: 워크스페이스 내에서 보드를 생성/삭제할 수 있어야 한다.
* 범위:

  * 보드 생성 API 구현
  * 보드 삭제 API 구현

### Issue: 보드 멤버 관리 (BRD-106)

* 설명: 보드에 멤버를 추가/제거하고 역할(Role)을 관리한다.
* 범위:

  * 멤버 초대/추가/제거 기능
  * 멤버 역할 관리 (OWNER, MEMBER, VIEWER)

---

## Epic: 카드/리스트 관리 (예정)

### Issue: 리스트 관리 (BRD-107)

* 설명: 보드 내에서 리스트(컬럼)를 생성/수정/삭제할 수 있다.
* 범위:

  * 리스트 생성 API 구현
  * 리스트 수정 API 구현
  * 리스트 삭제 API 구현

### Issue: 카드 관리 (BRD-108)

* 설명: 리스트 내에서 카드를 생성/수정/삭제할 수 있다.
* 범위:

  * 카드 생성 API 구현
  * 카드 수정 API 구현
  * 카드 삭제 API 구현
