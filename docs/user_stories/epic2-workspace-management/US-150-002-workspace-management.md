# US-150-002: 워크스페이스 관리

**As a** 워크스페이스 소유자  
**I want to** 내 워크스페이스의 정보를 관리하고  
**So that** 필요에 따라 워크스페이스를 수정하거나 삭제할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 워크스페이스 정보 수정**
```gherkin
Given 사용자가 워크스페이스 소유자이고
And 워크스페이스 설정 페이지에 있고
And 새로운 워크스페이스 이름과 설명을 입력했을 때
When 저장 버튼을 클릭하면
Then 워크스페이스 정보가 업데이트되고
And "워크스페이스 정보가 업데이트되었습니다" 메시지가 표시된다
```

**✅ 성공 케이스 - 워크스페이스 삭제**
```gherkin
Given 사용자가 워크스페이스 소유자이고
And 워크스페이스에 보드가 없고
And 워크스페이스 설정 페이지에 있을 때
When 삭제 버튼을 클릭하고
And 워크스페이스 이름을 재입력하여 확인하면
Then 워크스페이스가 삭제되고
And 대시보드로 리다이렉트되고
And "워크스페이스가 삭제되었습니다" 메시지가 표시된다
```

**❌ 실패 케이스 - 보드가 있는 워크스페이스 삭제 시도**
```gherkin
Given 사용자가 워크스페이스 소유자이고
And 워크스페이스에 1개 이상의 보드가 있을 때
When 워크스페이스 삭제를 시도하면
Then "워크스페이스를 삭제하려면 먼저 모든 보드를 삭제해주세요" 오류 메시지가 표시되고
And 워크스페이스 삭제가 진행되지 않는다
```

**❌ 실패 케이스 - 권한이 없는 사용자의 수정 시도**
```gherkin
Given 사용자가 워크스페이스 소유자가 아니고
When 워크스페이스 정보를 수정하려고 시도하면
Then "워크스페이스를 수정할 권한이 없습니다" 오류 메시지가 표시되고
And 수정이 진행되지 않는다
```

**Priority:** High | **Story Points:** 4
