# US-703-001: 첨부파일

**As a** 사용자  
**I want to** 업무와 관련된 파일을 카드에 직접 첨부하여  
**So that** 관련 자료를 한 곳에서 관리할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 파일 첨부**
```gherkin
Given 사용자가 카드 상세 모달에 있을 때
When 첨부파일 추가 버튼을 클릭하고
And 10MB 이하의 파일을 선택하고
And 업로드하면
Then 파일이 카드에 첨부되고
And 파일명, 크기, 업로드 시간이 표시되고
And 카드 목록에서 첨부파일 아이콘이 표시되고
And 활동 내역에 "첨부파일 추가" 기록이 남는다
```

**✅ 성공 케이스 - 파일 다운로드**
```gherkin
Given 카드에 첨부파일이 있을 때
When 첨부파일을 클릭하면
Then 파일 다운로드가 시작되고
And 원본 파일명으로 다운로드된다
```

**✅ 성공 케이스 - 파일 삭제**
```gherkin
Given 사용자가 첨부파일을 올린 사용자이거나 보드 소유자일 때
When 첨부파일 삭제 버튼을 클릭하고
And 삭제를 확인하면
Then 첨부파일이 카드에서 제거되고
And 서버에서 파일이 삭제되고
And 활동 내역에 "첨부파일 삭제" 기록이 남는다
```

**❌ 실패 케이스 - 파일 크기 제한 초과**
```gherkin
Given 사용자가 10MB를 초과하는 파일을 업로드하려고 할 때
When 파일을 선택하면
Then "파일 크기는 10MB 이하여야 합니다" 오류 메시지가 표시되고
And 파일 업로드가 진행되지 않는다
```

**❌ 실패 케이스 - 지원하지 않는 파일 형식**
```gherkin
Given 사용자가 실행 파일(.exe) 등 보안상 위험한 파일을 업로드하려고 할 때
When 파일을 선택하면
Then "지원하지 않는 파일 형식입니다" 오류 메시지가 표시되고
And 파일 업로드가 진행되지 않는다
```

**Priority:** Low | **Story Points:** 8
