# US-LIMIT-001: 사용자당 제한 관리 `[P0]`

**As a** 사용자  
**I want to** 시스템 성능을 위한 합리적인 제한 내에서 서비스를 이용하고  
**So that** 안정적인 서비스 품질을 경험할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 제한 내 워크스페이스 생성
```gherkin
Given 사용자가 현재 5개의 워크스페이스를 가지고 있을 때
When 새로운 워크스페이스를 생성하면
Then 워크스페이스가 성공적으로 생성되고
And 사용자의 워크스페이스 수가 6개로 업데이트된다
```

### ❌ 실패 케이스 - 워크스페이스 수 제한 초과
```gherkin
Given 사용자가 이미 10개의 워크스페이스를 가지고 있을 때
When 새로운 워크스페이스를 생성하려고 시도하면
Then "사용자당 최대 10개의 워크스페이스만 생성할 수 있습니다" 오류 메시지가 표시되고
And 워크스페이스 생성이 진행되지 않는다
```

### ❌ 실패 케이스 - 보드 수 제한 초과
```gherkin
Given 워크스페이스에 이미 50개의 보드가 있을 때
When 새로운 보드를 생성하려고 시도하면
Then "워크스페이스당 최대 50개의 보드만 생성할 수 있습니다" 오류 메시지가 표시되고
And 보드 생성이 진행되지 않는다
```

**Priority:** High | **Story Points:** 4
