# US-LIMIT-002: 보드별 제한 관리 `[P0]`

**As a** 사용자  
**I want to** 보드 성능을 유지하면서 충분한 양의 콘텐츠를 관리하고  
**So that** 효율적으로 작업할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 제한 내 리스트 생성
```gherkin
Given 보드에 현재 15개의 리스트가 있을 때
When 새로운 리스트를 생성하면
Then 리스트가 성공적으로 생성되고
And 보드의 리스트 수가 16개로 업데이트된다
```

### ❌ 실패 케이스 - 리스트 수 제한 초과
```gherkin
Given 보드에 이미 20개의 리스트가 있을 때
When 새로운 리스트를 생성하려고 시도하면
Then "보드당 최대 20개의 리스트만 생성할 수 있습니다" 오류 메시지가 표시되고
And 리스트 생성이 진행되지 않는다
```

### ❌ 실패 케이스 - 카드 수 제한 초과
```gherkin
Given 리스트에 이미 100개의 카드가 있을 때
When 새로운 카드를 생성하려고 시도하면
Then "리스트당 최대 100개의 카드만 생성할 수 있습니다" 오류 메시지가 표시되고
And 카드 생성이 진행되지 않는다
```

### ✅ 성공 케이스 - 제한 임박 경고
```gherkin
Given 리스트에 95개의 카드가 있을 때
When 카드 생성 페이지에 접근하면
Then "리스트당 카드 제한(100개)에 근접했습니다" 경고 메시지가 표시되고
And 여전히 카드 생성은 가능하다
```

**Priority:** High | **Story Points:** 5
