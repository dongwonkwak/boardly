# US-203-001: 카드 생성

**As a** 팀원  
**I want to** 내가 맡은 업무를 'To Do' 리스트에 카드로 생성하고  
**So that** 작업을 추적하고 관리할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 카드 생성**
```gherkin
Given 사용자가 보드에 있고
And 리스트당 카드 수가 100개 미만일 때
When 리스트 하단의 카드 추가 버튼을 클릭하고
And 카드 제목을 입력하고
And 선택적으로 설명을 입력하고
And 생성 버튼을 클릭하면
Then 새로운 카드가 리스트에 추가되고
And 카드가 해당 리스트의 맨 아래에 표시되고
And "카드가 생성되었습니다" 메시지가 표시된다
```

**❌ 실패 케이스 - 카드 수 제한 초과**
```gherkin
Given 리스트에 이미 100개의 카드가 있을 때
When 새로운 카드를 생성하려고 시도하면
Then "리스트당 최대 100개의 카드만 생성할 수 있습니다" 오류 메시지가 표시되고
And 카드 생성이 진행되지 않는다
```

**❌ 실패 케이스 - 빈 카드 제목**
```gherkin
Given 사용자가 카드 생성 모달에 있고
And 카드 제목을 입력하지 않았을 때
When 생성 버튼을 클릭하면
Then "카드 제목을 입력해주세요" 오류 메시지가 표시되고
And 카드 생성이 진행되지 않는다
```

**Priority:** High | **Story Points:** 4
