# US-601-002: 활동 피드 표시

**As a** 팀 리더  
**I want to** 팀원들의 최근 활동을 시간순으로 확인하여  
**So that** 프로젝트 진행도를 모니터링할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 보드 활동 피드 조회**
```gherkin
Given 사용자가 보드에 있을 때
When 활동 내역 탭을 클릭하면
Then 해당 보드의 모든 활동이 최신순으로 표시되고
And 각 활동의 수행자, 시간, 상세 내용이 표시되고
And 사용자가 설정한 언어로 메시지가 표시된다
```

**✅ 성공 케이스 - 실시간 활동 업데이트**
```gherkin
Given 사용자가 활동 피드를 보고 있고
And 다른 사용자가 보드에서 활동을 수행할 때
When 새로운 활동이 발생하면
Then 활동 피드가 자동으로 업데이트되고
And 새로운 활동이 목록 상단에 표시된다
```

**✅ 성공 케이스 - 활동 필터링**
```gherkin
Given 사용자가 활동 피드를 보고 있을 때
When 특정 활동 타입(카드 생성, 이동, 댓글 등)으로 필터링하면
Then 선택한 타입의 활동만 표시되고
And 필터 상태가 UI에 표시된다
```

**Priority:** High | **Story Points:** 5
