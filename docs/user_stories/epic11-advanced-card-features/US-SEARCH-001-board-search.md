# US-SEARCH-001: 보드 검색 `[P0]`

**As a** 사용자  
**I want to** 많은 보드 중에서 특정 보드를 빠르게 찾고  
**So that** 원하는 프로젝트에 즉시 접근할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 보드 제목 검색
```gherkin
Given 사용자가 대시보드에 있고
And 여러 보드가 존재할 때
When 검색창에 보드 제목의 일부를 입력하면
Then 해당 키워드가 포함된 보드들이 필터링되어 표시되고
And 검색 키워드가 하이라이트되어 표시되고
And 검색 결과 개수가 표시된다
```

### ✅ 성공 케이스 - 보드 설명 검색
```gherkin
Given 사용자가 대시보드에서 검색을 수행할 때
When 보드 설명에 포함된 키워드를 입력하면
Then 해당 키워드가 설명에 포함된 보드들이 표시되고
And 제목과 설명 모두에서 매칭이 가능하다
```

### ✅ 성공 케이스 - 검색 결과 없음
```gherkin
Given 사용자가 대시보드에서 검색을 수행할 때
When 어떤 보드와도 매칭되지 않는 키워드를 입력하면
Then "검색 결과가 없습니다" 메시지가 표시되고
And 새 보드 생성 옵션이 제공된다
```

### ✅ 성공 케이스 - 검색어 클리어
```gherkin
Given 사용자가 검색을 수행한 상태일 때
When 검색어를 지우거나 X 버튼을 클릭하면
Then 모든 보드가 다시 표시되고
And 검색 필터가 해제된다
```

**Priority:** High | **Story Points:** 4
