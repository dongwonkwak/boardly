# US-101-006: 비밀번호 변경 `[P0]`

**As a** 사용자  
**I want to** 비밀번호를 변경하여  
**So that** 계정 보안을 강화할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 비밀번호 변경
```gherkin
Given 사용자가 비밀번호 변경 페이지에 있고
And 현재 비밀번호를 올바르게 입력하고
And 유효한 새 비밀번호를 입력하고 확인했을 때
When 변경 버튼을 클릭하면
Then 비밀번호가 BCrypt로 해시되어 저장되고
And "비밀번호가 성공적으로 변경되었습니다" 메시지가 표시되고
And 활동 내역에 "비밀번호 변경" 기록이 남는다
```

### ❌ 실패 케이스 - 현재 비밀번호 불일치
```gherkin
Given 사용자가 비밀번호 변경 페이지에 있고
And 잘못된 현재 비밀번호를 입력했을 때
When 변경 버튼을 클릭하면
Then HTTP 401 Unauthorized 응답이 반환되고
And "현재 비밀번호가 올바르지 않습니다" 오류 메시지가 표시되고
And 비밀번호 변경이 진행되지 않는다
```

### ❌ 실패 케이스 - 새 비밀번호 복잡도 미충족
```gherkin
Given 사용자가 비밀번호 변경 페이지에 있고
And 올바른 현재 비밀번호를 입력하고
And 복잡도 요구사항을 충족하지 않는 새 비밀번호를 입력했을 때
When 변경 버튼을 클릭하면
Then HTTP 400 Bad Request 응답이 반환되고
And "새 비밀번호는 8자 이상, 대소문자 및 특수문자를 포함해야 합니다" 오류 메시지가 표시되고
And 비밀번호 변경이 진행되지 않는다
```

**Priority:** Medium | **Story Points:** 4
