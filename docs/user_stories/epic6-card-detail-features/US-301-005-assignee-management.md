# US-301-005: 담당자 할당

**As a** PM  
**I want to** 각 업무의 책임자를 명확히 지정하고  
**So that** 작업 분담을 체계적으로 관리할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 담당자 할당**
```gherkin
Given 사용자가 카드 상세 모달에 있고
And 보드에 여러 멤버가 있을 때
When 담당자 추가 버튼을 클릭하고
And 멤버 목록에서 담당자를 선택하면
Then 선택한 멤버가 카드 담당자로 할당되고
And 카드에 담당자 아바타가 표시되고
And 활동 내역에 "담당자 할당" 기록이 남는다
```

**✅ 성공 케이스 - 복수 담당자 할당**
```gherkin
Given 사용자가 카드 상세 모달에 있고
And 카드에 이미 담당자가 할당되어 있을 때
When 추가 담당자를 선택하면
Then 새로운 담당자가 기존 담당자와 함께 할당되고
And 모든 담당자의 아바타가 표시되고
And 활동 내역에 "담당자 추가" 기록이 남는다
```

**✅ 성공 케이스 - 담당자 제거**
```gherkin
Given 사용자가 카드 상세 모달에 있고
And 카드에 담당자가 할당되어 있을 때
When 담당자 아바타를 클릭하여 제거하면
Then 선택한 담당자가 카드에서 제거되고
And 카드에서 해당 담당자 아바타가 사라지고
And 활동 내역에 "담당자 제거" 기록이 남는다
```

**✅ 성공 케이스 - 자신을 담당자로 할당**
```gherkin
Given 사용자가 카드 상세 모달에 있을 때
When "나를 담당자로 지정" 버튼을 클릭하면
Then 현재 사용자가 카드 담당자로 할당되고
And 카드에 사용자의 아바타가 표시되고
And 활동 내역에 "담당자 할당" 기록이 남는다
```

**Priority:** High | **Story Points:** 4
