# US-LIMIT-003: 콘텐츠 크기 제한 `[P0]`

**As a** 사용자  
**I want to** 적절한 분량의 정보를 카드에 기록하여  
**So that** 가독성을 유지하고 시스템 성능을 보장할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 제한 내 카드 제목 입력
```gherkin
Given 사용자가 카드 제목을 입력할 때
When 200자의 제목을 입력하면
Then 제목이 성공적으로 저장되고
And 카드 목록에 정상 표시된다
```

### ❌ 실패 케이스 - 카드 제목 길이 초과
```gherkin
Given 사용자가 카드 제목을 입력할 때
When 255자를 초과하는 제목을 입력하면
Then "카드 제목은 최대 255자까지 입력할 수 있습니다" 오류 메시지가 표시되고
And 제목 저장이 진행되지 않는다
```

### ✅ 성공 케이스 - 제한 내 카드 설명 입력
```gherkin
Given 사용자가 카드 설명을 입력할 때
When 5,000자의 마크다운 설명을 입력하면
Then 설명이 성공적으로 저장되고
And 마크다운이 올바르게 렌더링된다
```

### ❌ 실패 케이스 - 카드 설명 길이 초과
```gherkin
Given 사용자가 카드 설명을 입력할 때
When 10,000자를 초과하는 설명을 입력하면
Then "카드 설명은 최대 10,000자까지 입력할 수 있습니다" 오류 메시지가 표시되고
And 설명 저장이 진행되지 않는다
```

### ✅ 성공 케이스 - 실시간 문자 수 표시
```gherkin
Given 사용자가 카드 제목이나 설명을 입력하고 있을 때
When 텍스트를 입력하면
Then 현재 문자 수와 최대 허용 문자 수가 실시간으로 표시되고
And 제한에 근접하면 경고 색상으로 표시된다
```

**Priority:** Medium | **Story Points:** 3
