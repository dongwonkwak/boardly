# US-101-008: 계정 삭제 `[P0]`

**As a** 사용자  
**I want to** 사용자 계정 및 관련 데이터를 영구 삭제하여  
**So that** 개인정보를 완전히 제거할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 계정 삭제
```gherkin
Given 사용자가 프로필 설정 페이지에 있을 때
When 계정 삭제 메뉴에 접근하고
And 비밀번호를 재확인하고
And 삭제 확인 대화상자에서 확인하면
Then 계정 및 모든 관련 데이터가 삭제되고
And 워크스페이스, 보드, 카드, 댓글이 모두 제거되고
And 랜딩 페이지로 리다이렉트되고
And 활동 내역에 "계정 삭제" 기록이 남는다
```

### ❌ 실패 케이스 - 비밀번호 재확인 실패
```gherkin
Given 사용자가 계정 삭제를 진행하고
And 잘못된 비밀번호를 입력했을 때
When 삭제를 시도하면
Then HTTP 401 Unauthorized 응답이 반환되고
And "비밀번호가 올바르지 않습니다" 오류 메시지가 표시되고
And 계정 삭제가 진행되지 않는다
```

**Priority:** Medium | **Story Points:** 5
