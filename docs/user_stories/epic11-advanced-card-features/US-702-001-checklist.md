# US-702-001: 체크리스트

**As a** 사용자  
**I want to** 복잡한 업무를 작은 단위로 나누어 관리하고  
**So that** 진행률을 시각적으로 확인할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 체크리스트 생성**
```gherkin
Given 사용자가 카드 상세 모달에 있을 때
When 체크리스트 추가 버튼을 클릭하고
And 체크리스트 제목을 입력하고
And 여러 개의 체크리스트 항목을 추가하면
Then 새로운 체크리스트가 카드에 추가되고
And 전체 진행률(0/5 완료)이 표시되고
And 카드 목록에서 체크리스트 아이콘과 진행률이 표시된다
```

**✅ 성공 케이스 - 체크리스트 항목 완료**
```gherkin
Given 카드에 체크리스트가 있을 때
When 체크리스트 항목의 체크박스를 클릭하면
Then 해당 항목이 완료 상태로 변경되고
And 전체 진행률이 업데이트되고 (1/5 완료)
And 완료된 항목에 취소선이 표시되고
And 활동 내역에 "체크리스트 항목 완료" 기록이 남는다
```

**✅ 성공 케이스 - 체크리스트 100% 완료 시**
```gherkin
Given 카드의 체크리스트 항목이 모두 완료되었을 때
When 마지막 항목을 체크하면
Then 진행률이 100%로 표시되고
And 체크리스트가 완료 상태로 표시되고
And "체크리스트가 완료되었습니다" 축하 메시지가 표시된다
```

**✅ 성공 케이스 - 체크리스트 항목 추가/삭제**
```gherkin
Given 카드에 체크리스트가 있을 때
When 새로운 항목을 추가하거나 기존 항목을 삭제하면
Then 체크리스트가 업데이트되고
And 전체 진행률이 재계산되고
And 활동 내역에 해당 변경사항이 기록된다
```

**Priority:** Medium | **Story Points:** 6
