# 워크스페이스 관리 유저스토리

## Epic: 워크스페이스 관리
**목표**: 사용자가 개인 및 팀 워크스페이스를 생성하고 관리할 수 있다.

---

## User Story 1: 워크스페이스 생성하기

**As a** 사용자  
**I want to** 새로운 워크스페이스를 생성할 수 있다  
**So that** 개인 또는 팀 프로젝트를 위한 공간을 만들 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 메인 페이지에 있다  
**When** "워크스페이스 생성" 버튼을 클릭한다  
**Then** 워크스페이스 생성 모달이 표시된다

**Given** 워크스페이스 생성 모달이 열려있다  
**When** 워크스페이스 이름을 입력한다  
**And** 워크스페이스 타입을 선택한다 (개인/팀)  
**And** 워크스페이스 설명을 입력한다 (선택사항)  
**And** "생성" 버튼을 클릭한다  
**Then** 새로운 워크스페이스가 생성된다  
**And** 생성된 워크스페이스 페이지로 이동한다

#### 비즈니스 규칙
- 워크스페이스 이름은 필수 입력 항목이다
- 워크스페이스 이름은 1-50자 사이여야 한다
- 워크스페이스 설명은 선택사항이며, 최대 200자까지 입력 가능하다
- 개인 워크스페이스는 사용자당 1개씩 자동 생성된다
- 팀 워크스페이스는 무제한으로 생성 가능하다
- 워크스페이스를 생성한 사용자는 자동으로 OWNER 역할을 받는다
- 동일한 사용자는 같은 워크스페이스 이름을 가질 수 없다

#### 예외 상황
**Given** 워크스페이스 생성 모달이 열려있다  
**When** 이름 없이 "생성" 버튼을 클릭한다  
**Then** "워크스페이스 이름을 입력해주세요" 오류 메시지가 표시된다

**Given** 워크스페이스 생성 모달이 열려있다  
**When** 이름을 50자를 초과하여 입력한다  
**And** "생성" 버튼을 클릭한다  
**Then** "워크스페이스 이름은 50자 이하여야 합니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **개인 워크스페이스 생성**: 개인용 워크스페이스 생성
2. **팀 워크스페이스 생성**: 팀용 워크스페이스 생성
3. **이름 누락**: 이름 없이 생성 시도
4. **이름 길이 초과**: 50자 초과 이름 입력
5. **설명 길이 초과**: 200자 초과 설명 입력
6. **중복 이름**: 동일한 워크스페이스 이름으로 생성 시도

## User Story 2: 워크스페이스 설정 관리하기

**As a** 워크스페이스 ADMIN  
**I want to** 워크스페이스 설정을 변경할 수 있다  
**So that** 워크스페이스를 필요에 맞게 커스터마이징할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 워크스페이스 페이지에 있다  
**When** "설정" 버튼을 클릭한다  
**Then** 워크스페이스 설정 페이지가 열린다

**Given** 워크스페이스 설정 페이지가 열려있다  
**When** 워크스페이스 이름을 변경한다  
**And** "저장" 버튼을 클릭한다  
**Then** 워크스페이스 이름이 변경된다  
**And** "설정이 저장되었습니다" 메시지가 표시된다

#### 설정 항목
- **기본 정보**: 워크스페이스 이름, 설명, 프로필 이미지
- **멤버 관리**: 팀원 목록, 권한 설정, 초대 관리
- **보안 설정**: 접근 권한, 공개/비공개 설정
- **알림 설정**: 이메일 알림, 푸시 알림 설정

#### 비즈니스 규칙
- 워크스페이스 ADMIN만 설정을 변경할 수 있다
- 워크스페이스 이름 변경 시 모든 멤버에게 알림이 발송된다
- 설정 변경은 실시간으로 모든 멤버에게 반영된다

#### 예외 상황
**Given** 워크스페이스 설정 페이지가 열려있다  
**When** ADMIN이 아닌 사용자가 설정을 변경하려고 한다  
**Then** "설정을 변경할 권한이 없습니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **이름 변경**: 워크스페이스 이름 변경
2. **설명 변경**: 워크스페이스 설명 변경
3. **권한 확인**: ADMIN이 아닌 사용자의 설정 변경 시도
4. **알림 발송**: 설정 변경 시 멤버 알림 확인

## User Story 3: 워크스페이스 멤버 관리하기

**As a** 워크스페이스 ADMIN  
**I want to** 워크스페이스 멤버를 관리할 수 있다  
**So that** 팀 구성원의 권한과 접근을 제어할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 워크스페이스 설정 페이지에 있다  
**When** "멤버 관리" 탭을 클릭한다  
**Then** 워크스페이스 멤버 목록이 표시된다

**Given** 워크스페이스 멤버 목록이 표시되어 있다  
**When** 특정 멤버의 권한을 변경한다  
**And** "저장" 버튼을 클릭한다  
**Then** 해당 멤버의 권한이 변경된다

#### 멤버 권한 관리
- **역할 변경**: ADMIN ↔ MEMBER 역할 변경
- **멤버 제거**: 워크스페이스에서 멤버 제거
- **멤버 정보**: 멤버의 활동 내역, 마지막 접속 시간 확인

#### 비즈니스 규칙
- 워크스페이스 ADMIN만 멤버를 관리할 수 있다
- 워크스페이스에는 최소 1명의 ADMIN이 있어야 한다
- 멤버 제거 시 해당 멤버의 모든 데이터는 보존된다
- 역할 변경 시 해당 멤버에게 알림이 발송된다

#### 예외 상황
**Given** 워크스페이스에 ADMIN이 1명만 있다  
**When** 해당 ADMIN의 역할을 변경하려고 한다  
**Then** "워크스페이스에는 최소 1명의 ADMIN이 필요합니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **역할 변경**: 멤버 역할 레벨 변경 (ADMIN ↔ MEMBER)
2. **멤버 제거**: 워크스페이스에서 멤버 제거
3. **최소 ADMIN**: 마지막 ADMIN 역할 변경 시도
4. **알림 발송**: 역할 변경 시 멤버 알림 확인

## User Story 4: 워크스페이스 삭제하기

**As a** 워크스페이스 ADMIN  
**I want to** 워크스페이스를 삭제할 수 있다  
**So that** 더 이상 필요하지 않은 워크스페이스를 정리할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 워크스페이스 설정 페이지에 있다  
**When** "워크스페이스 삭제" 버튼을 클릭한다  
**Then** 삭제 확인 모달이 표시된다

**Given** 삭제 확인 모달이 표시되어 있다  
**When** 워크스페이스 이름을 정확히 입력한다  
**And** "삭제 확인" 버튼을 클릭한다  
**Then** 워크스페이스가 삭제된다  
**And** 메인 페이지로 이동한다

#### 비즈니스 규칙
- 워크스페이스 ADMIN만 워크스페이스를 삭제할 수 있다
- 워크스페이스 삭제 시 모든 보드와 카드가 함께 삭제된다
- 삭제된 워크스페이스는 복구할 수 없다
- 삭제 확인을 위해 워크스페이스 이름을 정확히 입력해야 한다

#### 예외 상황
**Given** 삭제 확인 모달이 표시되어 있다  
**When** 잘못된 워크스페이스 이름을 입력한다  
**And** "삭제 확인" 버튼을 클릭한다  
**Then** "워크스페이스 이름이 일치하지 않습니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 삭제**: 올바른 이름으로 워크스페이스 삭제
2. **잘못된 이름**: 잘못된 이름으로 삭제 시도
3. **권한 확인**: ADMIN이 아닌 사용자의 삭제 시도
4. **데이터 삭제**: 워크스페이스 삭제 시 모든 데이터 삭제 확인

## User Story 5: 워크스페이스 소유권 이전하기

**As a** 워크스페이스 OWNER  
**I want to** 워크스페이스 소유권을 다른 ADMIN 멤버에게 이전할 수 있다  
**So that** 워크스페이스 관리를 다른 사람에게 위임할 수 있다

### 수용기준 (Acceptance Criteria)

#### 기본 플로우
**Given** 사용자가 워크스페이스 설정 페이지에 있다  
**When** "소유권 이전" 버튼을 클릭한다  
**Then** 소유권 이전 모달이 표시된다

**Given** 소유권 이전 모달이 열려있다  
**When** ADMIN 역할을 가진 멤버를 선택한다  
**And** "다음" 버튼을 클릭한다  
**Then** 이전 확인 화면이 표시된다

**Given** 이전 확인 화면이 표시되어 있다  
**When** "정말로 [새 소유자]에게 소유권을 이전하시겠습니까?" 확인 메시지를 확인한다  
**And** 비밀번호를 입력한다  
**And** "이전" 버튼을 클릭한다  
**Then** 소유권이 성공적으로 이전된다  
**And** 이전 OWNER에게 새로운 역할 선택 옵션이 제공된다

#### 비즈니스 규칙
- OWNER만 소유권을 이전할 수 있다
- 소유권은 ADMIN 역할을 가진 멤버에게만 이전 가능하다
- 워크스페이스 멤버가 1명인 경우 이전이 불가능하다
- 소유권 이전 시 이중 확인 절차가 필요하다
- 소유권 이전 시 OWNER의 비밀번호 재입력이 필요하다
- 소유권 이전 시 모든 멤버에게 알림이 발송된다
- 소유권 이전 이력은 영구적으로 기록된다

#### 예외 상황
**Given** 워크스페이스에 ADMIN 멤버가 없다  
**When** "소유권 이전" 버튼을 클릭한다  
**Then** "소유권을 이전할 ADMIN 멤버가 없습니다" 오류 메시지가 표시된다

**Given** 워크스페이스 멤버가 1명뿐이다  
**When** "소유권 이전" 버튼을 클릭한다  
**Then** "멤버가 1명뿐인 경우 소유권을 이전할 수 없습니다" 오류 메시지가 표시된다

**Given** 소유권 이전 확인 화면에서 잘못된 비밀번호를 입력한다  
**When** "이전" 버튼을 클릭한다  
**Then** "비밀번호가 일치하지 않습니다" 오류 메시지가 표시된다

#### 테스트 시나리오
1. **정상 이전**: ADMIN 멤버에게 소유권 이전
2. **ADMIN 부재**: ADMIN 멤버가 없는 경우 이전 시도
3. **단일 멤버**: 멤버가 1명뿐인 경우 이전 시도
4. **잘못된 비밀번호**: 비밀번호 오류 시 이전 시도
5. **알림 발송**: 소유권 이전 시 멤버 알림 확인
6. **이력 기록**: 소유권 이전 이력 기록 확인
