# US-402-001: 멤버 초대

**As a** 보드 소유자  
**I want to** 프로젝트에 필요한 팀원들을 보드에 초대하고  
**So that** 함께 협업할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 이메일로 멤버 초대**
```gherkin
Given 사용자가 보드 소유자이고
And 보드 설정 페이지에 있을 때
When 멤버 초대 버튼을 클릭하고
And 초대할 사용자의 이메일을 입력하고
And 역할(Editor/Viewer)을 선택하고
And 초대 버튼을 클릭하면
Then 초대 이메일이 발송되고
And 초대 상태가 PENDING으로 설정되고
And 초대받은 사용자가 워크스페이스 MEMBER 역할을 자동으로 가지게 되고
And "초대가 성공적으로 발송되었습니다" 메시지가 표시된다
```

**✅ 성공 케이스 - 초대 링크 생성**
```gherkin
Given 사용자가 보드 소유자이고
When 초대 링크 생성 버튼을 클릭하면
Then 7일간 유효한 초대 링크가 생성되고
And 링크를 복사할 수 있는 옵션이 제공되고
And 링크로 접속한 사용자는 자동으로 보드에 참여된다
```

**❌ 실패 케이스 - 이미 멤버인 사용자 초대**
```gherkin
Given 사용자가 이미 보드 멤버인 사용자의 이메일을 입력했을 때
When 초대를 시도하면
Then "이미 보드의 멤버입니다" 오류 메시지가 표시되고
And 초대가 진행되지 않는다
```

**❌ 실패 케이스 - 권한이 없는 사용자의 초대 시도**
```gherkin
Given 사용자가 보드 소유자가 아닐 때
When 멤버 초대를 시도하면
Then "멤버를 초대할 권한이 없습니다" 오류 메시지가 표시되고
And 초대 기능에 접근할 수 없다
```

**Priority:** High | **Story Points:** 6
