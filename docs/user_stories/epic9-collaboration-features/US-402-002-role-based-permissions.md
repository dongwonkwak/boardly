# US-402-002: 역할 기반 권한 관리

**As a** 워크스페이스 관리자  
**I want to** 각 멤버에게 역할에 맞는 권한을 부여하여  
**So that** 보안을 유지하고 적절한 접근 제어를 할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 보드 Editor 권한**
```gherkin
Given 사용자가 보드 Editor 역할을 가지고 있을 때
When 보드에 접근하면
Then 카드 생성, 수정, 이동이 가능하고
And 리스트 생성, 수정이 가능하고
And 댓글 작성, 수정, 삭제가 가능하고
And 보드 설정 변경은 불가능하다
```

**✅ 성공 케이스 - 보드 Viewer 권한**
```gherkin
Given 사용자가 보드 Viewer 역할을 가지고 있을 때
When 보드에 접근하면
Then 모든 카드와 리스트를 조회할 수 있고
And 댓글을 읽을 수 있지만 작성은 불가능하고
And 카드나 리스트의 수정/생성은 불가능하다
```

**✅ 성공 케이스 - 워크스페이스 소유자 절대 권한**
```gherkin
Given 사용자가 워크스페이스 소유자일 때
When 워크스페이스 내 모든 보드에 접근하면
Then 보드별 역할에 관계없이 모든 권한을 가지고
And 모든 보드를 수정, 삭제할 수 있고
And 모든 멤버의 역할을 변경할 수 있다
```

**❌ 실패 케이스 - 권한 없는 작업 시도**
```gherkin
Given 사용자가 Viewer 역할을 가지고 있을 때
When 카드를 생성하거나 수정하려고 시도하면
Then "이 작업을 수행할 권한이 없습니다" 오류 메시지가 표시되고
And 작업이 진행되지 않는다
```

**Priority:** High | **Story Points:** 8
