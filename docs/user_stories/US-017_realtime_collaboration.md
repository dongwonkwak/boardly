# US-017 실시간 동기화·협업 상태 (P1)

## 배경
여러 사용자가 동시에 보드에서 작업할 때 변경 사항을 실시간으로 동기화하고, 협업 상태(온라인/오프라인, 편집 중)를 표시한다.

참조: `SRS.md` 3.4.3, 3.4.4, 5.1(추가 엔티티 `WebSocket_Sessions`, `Collaboration_States`), `story_map.md` R2

## 사용자 스토리
- (동기화) 나는 사용자로서, 다른 사용자의 카드 이동/수정/댓글 추가가 즉시 내 화면에 반영되길 원한다.
- (상태 표시) 나는 사용자로서, 현재 누가 어떤 보드/카드를 보고/편집 중인지 알고 싶다.
- (권한 동기화) 나는 사용자로서, 권한 변경이나 초대 상태 변화가 실시간으로 반영되길 원한다.

## 수용 기준 (Acceptance Criteria)
1. 연결
   - 사용자별 실시간 연결을 유지하며 재연결을 처리한다.
2. 이벤트
   - 카드 이동/수정/댓글 추가 등 주요 이벤트를 실시간 반영한다.
   - 권한 관련 이벤트: 초대, 역할 변경, 권한 충돌 등 실시간 반영.
3. 상태 표시
   - 온라인/오프라인, 현재 활동 보드, 편집 중 리소스를 표시한다.
   - 권한 상태: 사용자의 현재 역할과 권한 범위 표시.
4. 충돌 처리(선택)
   - Last Write Wins 또는 충돌 알림 및 수동 해결 옵션 제공.
   - 권한 충돌 시 워크스페이스 권한 우선 원칙 적용.

## 비기능 (NFR)
- 지연 ≤ 300ms(내부망 기준), 연결 안정성
- 보안: 인증된 소켓, 권한 검증

## 테스트 시나리오 (샘플)
- 사용자 A가 카드 이동 → 사용자 B 화면 즉시 반영
- 권한 변경 → 모든 관련 사용자에게 실시간 반영
- 동시 수정 충돌 → 정책에 따라 해결
- 권한 충돌 → 워크스페이스 권한 우선 원칙 적용

## 범위
- 포함(P1): 실시간 이벤트 반영, 상태 표시, 재연결
- 제외: CRDT 기반 오프라인 병합(확장)
