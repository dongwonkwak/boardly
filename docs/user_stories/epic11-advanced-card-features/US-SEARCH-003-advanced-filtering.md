# US-SEARCH-003: 고급 필터링 `[P1]`

**As a** 사용자  
**I want to** 여러 조건을 조합하여 원하는 카드만 표시하고  
**So that** 복잡한 프로젝트에서도 효율적으로 작업할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 담당자별 필터링
```gherkin
Given 사용자가 보드에 있고
And 카드들에 다양한 담당자가 할당되어 있을 때
When 특정 담당자로 필터링하면
Then 해당 담당자가 할당된 카드들만 표시되고
And 필터 상태가 UI에 명확히 표시되고
And 필터를 해제할 수 있는 옵션이 제공된다
```

### ✅ 성공 케이스 - 라벨별 필터링
```gherkin
Given 사용자가 보드에 있고
And 카드들에 다양한 라벨이 적용되어 있을 때
When 특정 라벨로 필터링하면
Then 해당 라벨이 적용된 카드들만 표시되고
And 선택된 라벨이 시각적으로 강조되어 표시된다
```

### ✅ 성공 케이스 - 마감일별 필터링
```gherkin
Given 사용자가 보드에 있고
And 카드들에 다양한 마감일이 설정되어 있을 때
When 마감일 필터(오늘, 이번 주, 다음 주, 연체)를 선택하면
Then 해당 조건에 맞는 카드들만 표시되고
And 연체된 카드는 빨간색으로 강조되어 표시되고
And 마감일 임박 카드는 주황색으로 표시된다
```

### ✅ 성공 케이스 - 복합 필터링
```gherkin
Given 사용자가 여러 필터 조건을 설정했을 때 (담당자 + 라벨 + 마감일)
When 필터가 적용되면
Then 모든 조건을 만족하는 카드만 표시되고
And 적용된 모든 필터 조건이 필터 바에 표시되고
And 개별 필터를 제거할 수 있는 X 버튼이 제공되고
And "모든 필터 해제" 옵션이 제공된다
```

### ✅ 성공 케이스 - 완료 상태별 필터링
```gherkin
Given 사용자가 보드에 있을 때
When 완료 상태 필터(완료됨, 진행 중, 연체)를 선택하면
Then 해당 상태의 카드들만 표시되고
And 완료된 카드는 체크 표시와 함께 표시된다
```

**Priority:** Medium | **Story Points:** 7
