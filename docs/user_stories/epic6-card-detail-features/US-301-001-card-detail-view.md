# US-301-001: 카드 상세 조회

**As a** 사용자  
**I want to** 카드를 클릭하여 업무에 대한 상세 정보를 확인하고  
**So that** 작업 내용을 자세히 파악할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 카드 상세 모달 열기**
```gherkin
Given 사용자가 보드에 있고
And 카드가 존재할 때
When 카드를 클릭하면
Then 카드 상세 모달이 열리고
And 카드의 제목, 설명, 라벨, 마감일, 담당자가 표시되고
And 댓글 목록이 표시되고
And 활동 내역이 표시된다
```

**✅ 성공 케이스 - 카드 상세 모달 닫기**
```gherkin
Given 사용자가 카드 상세 모달을 보고 있을 때
When 닫기 버튼을 클릭하거나 ESC 키를 누르거나 모달 외부를 클릭하면
Then 카드 상세 모달이 닫히고
And 보드 화면으로 돌아간다
```

**Priority:** High | **Story Points:** 3
