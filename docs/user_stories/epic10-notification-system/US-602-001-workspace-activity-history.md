# US-602-001: 워크스페이스 활동 내역

**As a** 팀 리더  
**I want to** 팀 전체의 활동을 한 곳에서 조망하여  
**So that** 전체적인 진행 상황을 파악할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 워크스페이스 통합 활동 조회**
```gherkin
Given 사용자가 워크스페이스 관리자이고
And 워크스페이스에 여러 보드가 있을 때
When 워크스페이스 활동 내역을 조회하면
Then 모든 보드의 활동이 시간순으로 통합되어 표시되고
And 각 활동이 어느 보드에서 발생했는지 표시되고
And 보드별 필터링 옵션이 제공된다
```

**✅ 성공 케이스 - 팀원별 활동 필터링**
```gherkin
Given 사용자가 워크스페이스 활동 내역을 보고 있을 때
When 특정 팀원의 활동만 보기를 선택하면
Then 해당 팀원의 활동만 필터링되어 표시되고
And 팀원의 생산성과 참여도를 확인할 수 있다
```

**✅ 성공 케이스 - 활동 통계 제공**
```gherkin
Given 사용자가 워크스페이스 활동 내역을 조회할 때
When 통계 탭을 클릭하면
Then 일별/주별 활동 수치가 차트로 표시되고
And 가장 활발한 보드와 팀원이 표시되고
And 완료된 카드 수, 진행 중인 카드 수 등의 지표가 제공된다
```

**Priority:** Low | **Story Points:** 5
