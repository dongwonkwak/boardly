# US-203-004: 카드 복제 `[P0]`

**As a** 사용자  
**I want to** 비슷한 업무를 위해 기존 카드를 복제하여  
**So that** 시간을 절약할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 카드 복제
```gherkin
Given 사용자가 카드 상세 모달에 있고
And 리스트당 카드 수가 100개 미만이고
And 사용자가 'content:write' 권한을 가지고 있을 때
When 복제 버튼을 클릭하고
And 새로운 카드 제목을 입력하거나 기본값(" 복사본")을 사용하고
And 복제를 확인하면
Then 기존 카드의 모든 내용(제목, 설명, 라벨, 마감일)이 복사되고
And 새로운 카드가 같은 리스트에 생성되고
And "카드가 성공적으로 복제되었습니다" 메시지가 표시되고
And 활동 내역에 "카드 복제" 기록이 남는다
```

### ❌ 실패 케이스 - 카드 수 제한으로 인한 복제 실패
```gherkin
Given 사용자가 카드를 복제하려고 하고
And 리스트에 이미 100개의 카드가 있을 때
When 복제를 시도하면
Then HTTP 422 Unprocessable Entity 응답이 반환되고
And "리스트당 최대 100개의 카드만 생성할 수 있습니다" 오류 메시지가 표시되고
And 카드 복제가 진행되지 않는다
```

**Priority:** Medium | **Story Points:** 3
