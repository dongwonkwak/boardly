# US-301-003: 라벨 관리

**As a** 사용자  
**I want to** 업무의 성격이나 우선순위를 시각적으로 구분하고  
**So that** 카드를 효율적으로 분류할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 카드에 라벨 추가**
```gherkin
Given 사용자가 카드 상세 모달에 있고
And 보드에 라벨이 생성되어 있을 때
When 라벨 추가 버튼을 클릭하고
And 사용 가능한 라벨 목록에서 라벨을 선택하면
Then 선택한 라벨이 카드에 추가되고
And 카드 목록에서 라벨이 시각적으로 표시되고
And 활동 내역에 "라벨 추가" 기록이 남는다
```

**✅ 성공 케이스 - 새 라벨 생성**
```gherkin
Given 사용자가 카드 상세 모달의 라벨 관리에 있을 때
When 새 라벨 생성 버튼을 클릭하고
And 라벨 이름과 색상을 선택하고
And 생성하면
Then 새로운 라벨이 보드에 추가되고
And 해당 라벨이 카드에 적용되고
And 다른 카드에서도 사용할 수 있게 된다
```

**✅ 성공 케이스 - 카드에서 라벨 제거**
```gherkin
Given 사용자가 카드 상세 모달에 있고
And 카드에 라벨이 적용되어 있을 때
When 라벨을 클릭하여 제거하거나 라벨 관리에서 제거하면
Then 선택한 라벨이 카드에서 제거되고
And 카드 목록에서 라벨 표시가 사라지고
And 활동 내역에 "라벨 제거" 기록이 남는다
```

**❌ 실패 케이스 - 빈 라벨 이름으로 생성**
```gherkin
Given 사용자가 새 라벨을 생성하려고 하고
And 라벨 이름을 입력하지 않았을 때
When 생성 버튼을 클릭하면
Then "라벨 이름을 입력해주세요" 오류 메시지가 표시되고
And 라벨 생성이 진행되지 않는다
```

**Priority:** High | **Story Points:** 4
