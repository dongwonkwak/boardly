# Boardly 스토리 맵 (Story Map)

## 📋 개요
칸반 보드 기반 프로젝트 관리 도구 'Boardly'의 사용자 여정과 기능 스토리를 체계적으로 정리한 스토리 맵입니다.

---

## 🎯 타겟 사용자 (Target Personas)

### 👤 박준서 (32세) - 스타트업 PM
- **역할**: 5명 규모 개발팀 관리, 애자일 스프린트 관리
- **주요 니즈**: 실시간 업무 현황 파악, 시각적 스프린트 관리
- **Pain Points**: 매일 싱크업 미팅 시간 소모, 업무 병목 지점 파악 어려움

### 👤 김지아 (28세) - 프리랜서 마케터
- **역할**: 다중 클라이언트 마케팅 캠페인 운영
- **주요 니즈**: 클라이언트별 프로젝트 분리 관리, 마감일 관리
- **Pain Points**: 프로젝트별 진행 상황 혼재, 마감일 놓칠 위험

### 👤 이하은 (22세) - 대학생 팀플 조장
- **역할**: 4명 조원과 졸업 과제 준비
- **주요 니즈**: 조원 역할 분담, 자료 취합, 무료 협업툴
- **Pain Points**: 조원 참여 저조, 자료 제출 현황 파악 어려움

---

## 🚀 Phase 0: MVP 필수 기능

### 👤 Epic 1: 사용자 관리
**목표**: 사용자가 서비스에 가입하고 계정을 관리할 수 있는 기본 기능

#### F-101-1: 회원가입 `[P0]`
- **기능**: 이메일, 성, 이름, 비밀번호로 회원가입
- **사용자 스토리**: *신규 사용자로서, 이메일과 비밀번호를 사용하여 계정을 생성하고 서비스를 이용하고 싶다.*

#### F-101-2: 로그인/로그아웃 `[P0]`
- **기능**: 이메일과 비밀번호로 로그인, JWT 토큰 인증
- **사용자 스토리**: *가입한 사용자로서, 내 계정으로 로그인하여 개인화된 서비스를 이용하고 싶다.*

#### F-101-3: 프로필 관리 `[P0]`
- **기능**: 프로필 조회, 수정, 비밀번호 변경, 언어 설정
- **사용자 스토리**: *사용자로서, 내 프로필 정보를 확인하고 필요시 수정하며 보안을 위해 비밀번호를 변경하고 싶다.*
