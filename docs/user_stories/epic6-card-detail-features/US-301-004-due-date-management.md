# US-301-004: 마감일 관리

**As a** 사용자  
**I want to** 업무의 마감일을 설정하고  
**So that** 기한을 놓치지 않도록 관리할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 마감일 설정**
```gherkin
Given 사용자가 카드 상세 모달에 있을 때
When 마감일 설정 버튼을 클릭하고
And 날짜와 시간을 선택하고
And 저장하면
Then 마감일이 카드에 설정되고
And 카드 목록에서 마감일 아이콘이 표시되고
And 활동 내역에 "마감일 설정" 기록이 남는다
```

**✅ 성공 케이스 - 마감일 완료 처리**
```gherkin
Given 사용자가 마감일이 설정된 카드를 보고 있을 때
When 마감일 완료 체크박스를 클릭하면
Then 마감일이 완료 상태로 변경되고
And 마감일 표시가 완료 스타일로 변경되고
And 활동 내역에 "마감일 완료" 기록이 남는다
```

**✅ 성공 케이스 - 마감일 수정**
```gherkin
Given 사용자가 마감일이 설정된 카드를 보고 있을 때
When 마감일을 클릭하여 편집하고
And 새로운 날짜와 시간을 선택하고
And 저장하면
Then 마감일이 업데이트되고
And 활동 내역에 "마감일 변경" 기록이 남는다
```

**✅ 성공 케이스 - 마감일 제거**
```gherkin
Given 사용자가 마감일이 설정된 카드를 보고 있을 때
When 마감일 제거 버튼을 클릭하고
And 제거를 확인하면
Then 마감일이 카드에서 제거되고
And 카드 목록에서 마감일 아이콘이 사라지고
And 활동 내역에 "마감일 제거" 기록이 남는다
```

**✅ 성공 케이스 - 마감일 임박/초과 표시**
```gherkin
Given 카드에 마감일이 설정되어 있을 때
When 마감일이 24시간 이내로 임박하면
Then 마감일이 주황색으로 표시되고
When 마감일이 지나면
Then 마감일이 빨간색으로 표시된다
```

**Priority:** High | **Story Points:** 5
