# Boardly User Stories

## 📋 개요
Boardly 프로젝트의 사용자 스토리를 Epic별로 체계적으로 정리한 문서입니다. 각 스토리는 BDD(Behavior-Driven Development) 방식의 Given-When-Then 형식으로 작성되어 테스트 가능하고 명확한 요구사항을 제시합니다.

---

## 🚀 Phase 0: MVP 필수 기능

### 👤 Epic 1: 사용자 인증 및 관리

#### US-101-001: 회원가입 `[P0]`
**As a** 신규 사용자  
**I want to** 이메일, 성, 이름, 비밀번호를 사용하여 계정을 생성하고  
**So that** 서비스를 이용할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 유효한 정보로 회원가입**
```gherkin
Given 사용자가 회원가입 페이지에 있고
And 유효한 이메일 주소를 입력하고
And 8자 이상의 복합 비밀번호(대소문자, 특수문자 포함)를 입력하고
And 1-50자의 한글/영문 성, 이름을 입력했을 때
When 회원가입 버튼을 클릭하면
Then 계정이 성공적으로 생성되고
And 비밀번호가 BCrypt로 해시되어 저장되고
And 로그인 페이지로 리다이렉트되고
And "회원가입이 완료되었습니다" 메시지가 표시된다
```

**❌ 실패 케이스 - 이메일 중복**
```gherkin
Given 사용자가 회원가입 페이지에 있고
And 이미 등록된 이메일 주소를 입력했을 때
When 회원가입 버튼을 클릭하면
Then HTTP 409 Conflict 응답이 반환되고
And "이미 사용 중인 이메일입니다" 오류 메시지가 표시되고
And 회원가입이 진행되지 않는다
```

**❌ 실패 케이스 - 비밀번호 복잡도 미충족**
```gherkin
Given 사용자가 회원가입 페이지에 있고
And 8자 미만이거나 대소문자/특수문자가 없는 비밀번호를 입력했을 때
When 회원가입 버튼을 클릭하면
Then HTTP 400 Bad Request 응답이 반환되고
And "비밀번호는 8자 이상, 대소문자 및 특수문자를 포함해야 합니다" 오류 메시지가 표시되고
And 회원가입이 진행되지 않는다
```

**❌ 실패 케이스 - 필수 필드 누락**
```gherkin
Given 사용자가 회원가입 페이지에 있고
And 이메일, 성, 이름 중 하나라도 입력하지 않았을 때
When 회원가입 버튼을 클릭하면
Then HTTP 400 Bad Request 응답이 반환되고
And "모든 필수 정보를 입력해주세요" 오류 메시지가 표시되고
And 회원가입이 진행되지 않는다
```

**Priority:** High | **Story Points:** 5

#### US-101-002: 로그인 `[P0]`
**As a** 가입한 사용자  
**I want to** 내 계정으로 로그인하여  
**So that** 개인화된 서비스를 이용할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 올바른 인증 정보로 로그인**
```gherkin
Given 사용자가 로그인 페이지에 있고
And 등록된 이메일과 올바른 비밀번호를 입력했을 때
When 로그인 버튼을 클릭하면
Then JWT 토큰이 발급되고
And 로컬 스토리지에 토큰이 저장되고
And 대시보드 페이지로 리다이렉트되고
And 사용자 세션이 활성화된다
```

**❌ 실패 케이스 - 잘못된 인증 정보**
```gherkin
Given 사용자가 로그인 페이지에 있고
And 존재하지 않는 이메일 또는 잘못된 비밀번호를 입력했을 때
When 로그인 버튼을 클릭하면
Then HTTP 401 Unauthorized 응답이 반환되고
And "이메일 또는 비밀번호가 올바르지 않습니다" 오류 메시지가 표시되고
And 로그인이 진행되지 않는다
```

**❌ 실패 케이스 - Rate Limiting 초과**
```gherkin
Given 사용자가 짧은 시간 내에 5회 이상 로그인 실패를 했을 때
When 추가 로그인을 시도하면
Then HTTP 429 Too Many Requests 응답이 반환되고
And "잠시 후 다시 시도해주세요" 메시지가 표시되고
And 일정 시간 동안 로그인이 차단된다
```

**Priority:** High | **Story Points:** 4

### 🏢 Epic 2: 워크스페이스 관리

#### US-150-001: 워크스페이스 생성 `[P0]`
**As a** 사용자  
**I want to** 개인 프로젝트와 팀 프로젝트를 분리하여 관리하기 위해 별도의 워크스페이스를 만들고  
**So that** 프로젝트를 체계적으로 구분할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - Personal 워크스페이스 생성**
```gherkin
Given 사용자가 대시보드에 있고
And 사용자당 워크스페이스 수가 10개 미만일 때
When 워크스페이스 생성 버튼을 클릭하고
And 워크스페이스 이름을 입력하고
And Personal 타입을 선택하고
And 생성 버튼을 클릭하면
Then 새로운 Personal 워크스페이스가 생성되고
And 사용자가 워크스페이스 소유자(OWNER) 역할을 가지게 되고
And 워크스페이스 목록에 표시되고
And "워크스페이스가 성공적으로 생성되었습니다" 메시지가 표시된다
```

**✅ 성공 케이스 - Team 워크스페이스 생성**
```gherkin
Given 사용자가 대시보드에 있고
And 사용자당 워크스페이스 수가 10개 미만일 때
When 워크스페이스 생성 버튼을 클릭하고
And 워크스페이스 이름을 입력하고
And Team 타입을 선택하고
And 생성 버튼을 클릭하면
Then 새로운 Team 워크스페이스가 생성되고
And 사용자가 워크스페이스 소유자(OWNER) 역할을 가지게 되고
And 워크스페이스 목록에 표시되고
And 멤버 초대 기능이 활성화된다
```

**❌ 실패 케이스 - 워크스페이스 수 제한 초과**
```gherkin
Given 사용자가 이미 10개의 워크스페이스를 가지고 있고
When 새로운 워크스페이스를 생성하려고 시도하면
Then HTTP 422 Unprocessable Entity 응답이 반환되고
And "워크스페이스는 최대 10개까지 생성할 수 있습니다" 오류 메시지가 표시되고
And 워크스페이스 생성이 진행되지 않는다
```

**❌ 실패 케이스 - 빈 워크스페이스 이름**
```gherkin
Given 사용자가 워크스페이스 생성 모달에 있고
And 워크스페이스 이름을 입력하지 않았을 때
When 생성 버튼을 클릭하면
Then HTTP 400 Bad Request 응답이 반환되고
And "워크스페이스 이름을 입력해주세요" 오류 메시지가 표시되고
And 워크스페이스 생성이 진행되지 않는다
```

**Priority:** High | **Story Points:** 5
