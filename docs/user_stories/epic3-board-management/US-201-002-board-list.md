# US-201-002: 보드 목록 조회 `[P0]`

**As a** 사용자  
**I want to** 내가 생성한 또는 참여한 모든 보드를 한눈에 보고  
**So that** 자주 사용하는 보드를 즐겨찾기로 관리할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 보드 목록 조회
```gherkin
Given 사용자가 대시보드에 있고
And 사용자가 여러 보드에 접근 권한을 가지고 있을 때
When 대시보드를 로드하면
Then 'board:read' 권한이 있는 모든 보드가 최신순으로 표시되고
And 각 보드의 제목, 설명, 생성일이 표시되고
And 즐겨찾기 표시가 보이고
And 보드별 멤버 수와 카드 수가 표시된다
```

### ✅ 성공 케이스 - 즐겨찾기 설정/해제
```gherkin
Given 사용자가 보드 목록을 보고 있을 때
When 보드의 즐겨찾기 버튼을 클릭하면
Then 즐겨찾기 상태가 토글되고
And 즐겨찾기된 보드가 목록 상단에 표시되고
And 변경사항이 즉시 저장된다
```

### ✅ 성공 케이스 - 빈 보드 목록
```gherkin
Given 사용자가 생성하거나 참여한 보드가 없을 때
When 대시보드에 접근하면
Then "아직 보드가 없습니다" 메시지가 표시되고
And "첫 번째 보드 만들기" 버튼이 제공된다
```

### ✅ 성공 케이스 - 보드 검색
```gherkin
Given 사용자가 대시보드에서 검색창에 키워드를 입력할 때
When 검색을 실행하면
Then 제목이나 설명에 해당 키워드가 포함된 보드만 표시되고
And 검색 결과 개수가 표시된다
```

**Priority:** High | **Story Points:** 4
