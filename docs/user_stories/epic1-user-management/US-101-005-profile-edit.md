# US-101-005: 프로필 수정 `[P0]`

**As a** 사용자  
**I want to** 내 프로필 정보를 수정하여  
**So that** 최신 정보를 유지할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 프로필 정보 수정
```gherkin
Given 사용자가 프로필 편집 페이지에 있고
And 유효한 성, 이름을 입력하고
And 언어 설정을 변경했을 때
When 저장 버튼을 클릭하면
Then 프로필 정보가 업데이트되고
And "프로필이 성공적으로 업데이트되었습니다" 메시지가 표시되고
And 변경된 언어로 UI가 즉시 반영되고
And 활동 내역에 "프로필 수정" 기록이 남는다
```

### ❌ 실패 케이스 - 유효하지 않은 입력
```gherkin
Given 사용자가 프로필 편집 페이지에 있고
And 빈 값이거나 50자를 초과하는 성/이름을 입력했을 때
When 저장 버튼을 클릭하면
Then HTTP 400 Bad Request 응답이 반환되고
And "성과 이름은 1-50자 사이여야 합니다" 오류 메시지가 표시되고
And 프로필 업데이트가 진행되지 않는다
```

**Priority:** Medium | **Story Points:** 3
