# US-201-003: 보드 수정/삭제

**As a** 보드 소유자  
**I want to** 프로젝트 변경에 따라 보드 정보를 수정하거나  
**So that** 완료된 프로젝트의 보드를 정리할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 보드 정보 수정**
```gherkin
Given 사용자가 보드 소유자이고
And 보드 설정 페이지에 있고
And 새로운 보드 이름과 설명을 입력했을 때
When 저장 버튼을 클릭하면
Then 보드 정보가 업데이트되고
And "보드 정보가 업데이트되었습니다" 메시지가 표시된다
```

**✅ 성공 케이스 - 보드 복제**
```gherkin
Given 사용자가 보드 소유자이고
And 워크스페이스당 보드 수가 50개 미만일 때
When 보드 복제 버튼을 클릭하고
And 새로운 보드 이름을 입력하면
Then 기존 보드의 구조(리스트, 카드)가 복사되고
And 새로운 보드가 생성되고
And "보드가 성공적으로 복제되었습니다" 메시지가 표시된다
```

**✅ 성공 케이스 - 보드 삭제 (휴지통으로 이동)**
```gherkin
Given 사용자가 보드 소유자이고
And 보드 설정 페이지에 있을 때
When 삭제 버튼을 클릭하고
And 확인 대화상자에서 삭제를 확인하면
Then 보드가 휴지통으로 이동되고
And 30일 후 자동 삭제 스케줄이 설정되고
And "보드가 휴지통으로 이동되었습니다" 메시지가 표시된다
```

**❌ 실패 케이스 - 권한이 없는 사용자의 수정 시도**
```gherkin
Given 사용자가 보드 소유자가 아니고
When 보드 정보를 수정하려고 시도하면
Then "보드를 수정할 권한이 없습니다" 오류 메시지가 표시되고
And 수정이 진행되지 않는다
```

**Priority:** High | **Story Points:** 6
