# US-601-002: 활동 피드 표시 `[P0]`

**As a** 팀 리더  
**I want to** 팀원들의 최근 활동을 시간순으로 확인하여  
**So that** 프로젝트 진행도를 모니터링할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 보드 활동 피드 조회
```gherkin
Given 사용자가 보드에 있고
And 사용자가 'content:read' 권한을 가지고 있을 때
When 활동 내역 탭을 클릭하면
Then 해당 보드의 모든 활동이 최신순(timestamp DESC)으로 표시되고
And 각 활동의 수행자, 시간, 상세 내용이 표시되고
And 사용자가 설정한 언어로 메시지가 표시되고
And 페이지네이션이 적용된다
```

### ✅ 성공 케이스 - 활동 타입별 아이콘 표시
```gherkin
Given 사용자가 활동 피드를 보고 있을 때
When 다양한 활동 타입이 표시되면
Then 각 활동 타입별로 구분되는 아이콘이 표시되고
And 카드 생성, 이동, 댓글 등이 시각적으로 구분되고
And 색상으로 활동의 중요도가 구분된다
```

### ✅ 성공 케이스 - 활동 필터링
```gherkin
Given 사용자가 활동 피드를 보고 있을 때
When 특정 활동 타입(카드 생성, 이동, 댓글 등)으로 필터링하면
Then 선택한 타입의 활동만 표시되고
And 필터 상태가 UI에 표시되고
And URL 파라미터에 필터 정보가 반영된다
```

### ✅ 성공 케이스 - 상대적 시간 표시
```gherkin
Given 활동이 표시될 때
When 활동 시간이 렌더링되면
Then "2시간 전", "3일 전" 등 상대적 시간으로 표시되고
And 마우스 오버 시 정확한 절대 시간이 툴팁으로 표시되고
And 언어 설정에 따라 현지화된 시간 형식이 사용된다
```

**Priority:** High | **Story Points:** 5
