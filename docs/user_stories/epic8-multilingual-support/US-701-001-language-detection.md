# US-701-001: 언어 감지 및 설정

**As a** 한국어 사용자  
**I want to** 한국어 인터페이스로 서비스를 이용하고  
**So that** 편리하게 서비스를 사용할 수 있다.

**Scenarios:**

**✅ 성공 케이스 - 브라우저 언어 자동 감지**
```gherkin
Given 신규 사용자가 처음 서비스에 접속하고
And 브라우저의 Accept-Language가 한국어로 설정되어 있을 때
When 서비스에 접속하면
Then UI가 한국어로 표시되고
And 언어 설정이 로컬 스토리지에 저장된다
```

**✅ 성공 케이스 - 수동 언어 변경**
```gherkin
Given 사용자가 서비스를 이용하고 있을 때
When 언어 설정 메뉴에서 다른 언어(영어/한국어)를 선택하면
Then UI가 즉시 선택한 언어로 변경되고
And 언어 설정이 로컬 스토리지에 저장되고
And 다음 접속 시에도 선택한 언어가 유지된다
```

**✅ 성공 케이스 - 지원하지 않는 언어 처리**
```gherkin
Given 사용자의 브라우저가 지원하지 않는 언어(일본어, 중국어 등)로 설정되어 있을 때
When 서비스에 접속하면
Then 기본 언어인 영어로 UI가 표시되고
And 영어 설정이 로컬 스토리지에 저장된다
```

**Priority:** Medium | **Story Points:** 3
