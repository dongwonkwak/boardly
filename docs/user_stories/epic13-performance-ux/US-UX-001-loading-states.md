# US-UX-001: 로딩 상태 관리 `[P0]`

**As a** 사용자  
**I want to** 시스템이 작업을 처리하고 있음을 시각적으로 확인하고  
**So that** 현재 상태를 파악하고 적절히 대기할 수 있다.

## Scenarios

### ✅ 성공 케이스 - 페이지 로딩 인디케이터
```gherkin
Given 사용자가 보드나 대시보드에 접근할 때
When 데이터를 로딩하는 동안
Then 스켈레톤 UI 또는 스피너가 표시되고
And 로딩이 완료되면 실제 콘텐츠로 대체되고
And 로딩 시간이 2초를 초과하지 않는다
```

### ✅ 성공 케이스 - 카드 이동 중 로딩 상태
```gherkin
Given 사용자가 카드를 드래그 앤 드롭으로 이동할 때
When 서버 처리가 진행되는 동안
Then 카드가 임시로 새 위치에 표시되고
And 처리 중임을 나타내는 시각적 표시가 나타나고
And 처리 완료 시 확정된 상태로 변경된다
```

### ✅ 성공 케이스 - 버튼 로딩 상태
```gherkin
Given 사용자가 폼 제출이나 액션 버튼을 클릭할 때
When 서버 요청이 진행되는 동안
Then 버튼이 비활성화되고
And 로딩 스피너가 버튼 내부에 표시되고
And 중복 제출이 방지된다
```

**Priority:** High | **Story Points:** 4
